# 푸앵카레 볼 기반 리만 기저 인코딩: 미분의 위상-비트 표현과 128비트 파라메트릭 압축

## 초록

본 논문은 신경망 가중치 블록을 128비트 상태로 파라미터화하고, 그 상태 위에서 순전파와 역전파를 직접 수행하는 리만 기저 인코딩(RBE)의 수학적 기초를 재유도한다. 핵심 기여는 다음 세 가지다.

1. **미분의 위상-비트 표현**: 미분 연산에 대해 닫힌 함수족 $\{A\sin(\omega t + \varphi)\}$ 에서 미분은 위상 이동 $\varphi \mapsto \varphi + \pi/2$ 와 진폭 스케일 $A \mapsto A\omega$ 로 정확히 표현된다. 위상을 $b$비트 정수 레지스터로 양자화하면 ($4 \mid 2^b$), 미분은 반올림 오차가 전혀 없는 **정수 덧셈 $q \mapsto q + 2^{b-2} \pmod{2^b}$** 이 된다. 고전적 순환 $\sin \to \cos \to -\sin \to -\cos$ 은 이 레지스터 상위 2비트의 $\mathbb{Z}/4$ 궤도로 정확히 형식화된다. 쌍곡 트랙 $\{\sinh, \cosh\}$ 은 1비트 라벨 플립($\mathbb{Z}/2$)으로 닫힌다.
2. **순환 불가능성의 증명과 정직한 처리**: $\tanh$ 는 유한 상태 기계로 미분 탑을 표현할 수 없음을 증명하고(정리 3.3), 역전파에 1차 도함수만 필요하다는 사실에 근거해 1차 미분 테이블로 처리한다. 이는 기존 문서의 4-순환 주장을 정정한다.
3. **압축률과 속도의 한계 분석**: rate-distortion 이론으로 "일반 행렬의 1000:1 압축 + 저 RMSE"가 불가능함을 명시하고(정리 8.1), 본 방식이 성립하는 조건 — 구조 가정 하의 파라메트릭 압축 + 잔차 코딩 — 을 유도한다. 루프라인 모델로 속도 이득이 성립하는 정확한 조건 $C_g < 4I^* - 2$ (배치 1 추론)과 대배치에서의 상한(패리티)을 유도한다.

제2부(12–16장)는 본 방식의 대상을 재정의한다: RBE 가 부호화하는 것은 가중치 표본이 아니라 **평면 위의 연속 장(field)**이며, 부호화 단위는 블록이 아니라 층 전체다(15장: 뉴런 잠재 좌표 + 커널 장 = 묶인 고랭크 인수분해). 장 클래스의 ε-엔트로피는 해상도와 무관하므로 정리 8.1 의 한계는 장 부호화에 적용되지 않으며(12장), 쌍곡 평면의 푸리에 이론(Helgason 변환)의 평면파가 올바른 원자 기저를 제공하고(13장), 위상-비트 미분은 원자별 상수 위상 이동으로 일반화된다(정리 13.2). 푸앵카레 평면이 연속 웨이블릿 변환의 위치-스케일 공간과 등거리 동형이라는 사실이 이 구성의 기하학적 근거다.

이전 판의 실측 근거 없는 실험 수치와 성능 주장은 모두 삭제하였으며, 측정이 필요한 항목은 10장과 15장의 검증 프로토콜로 분리하였다.

**키워드**: 푸앵카레 볼, 위상 양자화, 상태 순환 미분, 파라메트릭 압축, rate-distortion, 루프라인 분석

## 1. 서론

### 1.1 문제 설정

대규모 신경망 추론의 병목은 배치가 작을 때 가중치 메모리 트래픽이다. $M \times N$ GEMV 는 연산 $2MN$ FLOP 에 대해 가중치 $4MN$ 바이트를 읽으므로 연산 강도가 $0.5$ FLOP/byte 에 불과하고, 이는 현대 하드웨어의 기계 균형점(machine balance, 통상 수십 FLOP/byte)보다 훨씬 낮아 메모리 대역폭에 결박된다. 가중치를 소수의 파라미터로부터 즉석 생성하면 트래픽을 제거할 수 있으나, 생성 비용과 표현력 손실이라는 두 대가를 치른다. 본 논문은 이 교환을 수학적으로 정확히 계량한다.

### 1.2 핵심 아이디어

RBE의 중심 아이디어는 **미분이라는 연산 자체를 비트 상태 전이로 만드는 것**이다. 기저함수를 값이 아니라 양자화된 위상 상태로 저장하면:

- 순전파: 위상 레지스터로 기저함수를 평가한다.
- 역전파: 도함수가 필요할 때, 위상 레지스터에 상수를 더한 **같은 평가기**를 재사용한다. 별도의 미분 코드 경로가 없고, 그래디언트 1회 비용 = 순전파 1회 비용이다.
- $n$계 도함수: 상수를 $n$번 더하면 된다. 상태 전이 자체는 $O(1)$ 정수 연산이다.

푸앵카레 볼은 이 체계에서 두 가지 역할을 한다. (i) 반지름 좌표 $r \in [0,1)$ 을 쌍곡 거리 $d_h(r) = 2\,\mathrm{artanh}(r)$ 로 재매개화하면, 유계 구간의 고정 비트로 비유계 스케일 축을 부동소수점과 유사한 상대 정밀도로 담는 컴팩트 컴팬딩(companding)이 된다(7.1절). (ii) 리만 계량이 경계 근처에서 그래디언트 스텝을 자동으로 감쇠시켜, 클리핑 없이 제약 $r < 1$ 이 유지된다(7.2절).

### 1.3 정직성 원칙

본 논문은 다음을 준수한다. 모든 명제는 유도 또는 증명을 동반하고, 증명 불가능한 것은 가정임을 명시한다. 실측되지 않은 수치는 제시하지 않으며, 예시 계산은 "예시 사양"임을 명시한다. 이전 판에서 오류로 확인된 주장(무한 정보 저장, 쌍곡 CORDIC 게인 0.6073, $\mathrm{sech}^2 \to \sinh$ 순환, 측지선 공식, 재현 불가 실험 표)은 본 판에서 정정 또는 삭제되었다.

## 2. 수학적 예비: 푸앵카레 볼의 표준 공식

이하는 모두 표준 결과이며(Ungar 2008; Ganea et al. 2018), 이후 장의 유도에 사용된다. 이전 판의 비표준 공식들을 대체한다.

푸앵카레 볼 $\mathbb{D}^n = \{x \in \mathbb{R}^n : \|x\| < 1\}$, 곡률 $K = -1$.

**계량**:
$$ds^2 = \lambda_x^2 \sum_i dx_i^2, \qquad \lambda_x = \frac{2}{1 - \|x\|^2}$$

2차원 극좌표 $(r, \theta)$ 에서:
$$ds^2 = \frac{4\,(dr^2 + r^2\,d\theta^2)}{(1-r^2)^2}, \qquad g_{rr} = \frac{4}{(1-r^2)^2}, \quad g_{\theta\theta} = \frac{4r^2}{(1-r^2)^2}$$

**원점 거리**: 계량을 적분하면
$$d_h(r) := d(0, r) = \int_0^r \frac{2\,ds}{1-s^2} = 2\,\mathrm{artanh}(r) = \ln\frac{1+r}{1-r}$$

**두 점 거리**:
$$d(x,y) = \mathrm{arcosh}\!\left(1 + \frac{2\|x-y\|^2}{(1-\|x\|^2)(1-\|y\|^2)}\right)$$

**뫼비우스 덧셈** (Ungar):
$$x \oplus y = \frac{(1 + 2\langle x,y\rangle + \|y\|^2)\,x + (1 - \|x\|^2)\,y}{1 + 2\langle x,y\rangle + \|x\|^2\|y\|^2}$$

**스칼라 곱**:
$$t \otimes x = \tanh\!\big(t\,\mathrm{artanh}\|x\|\big)\,\frac{x}{\|x\|}$$

**지수 사상**:
$$\mathrm{Exp}_x(v) = x \oplus \left(\tanh\!\left(\frac{\lambda_x \|v\|}{2}\right)\frac{v}{\|v\|}\right)$$

**측지선**: $\gamma(t) = x \oplus \big(t \otimes ((-x) \oplus y)\big)$, $\gamma(0) = x$, $\gamma(1) = y$.

**리만 그래디언트** (등각 계량이므로):
$$\mathrm{grad}\,f = \frac{1}{\lambda_x^2}\nabla f = \frac{(1-\|x\|^2)^2}{4}\nabla f,
\qquad
\mathrm{grad}_r = \frac{(1-r^2)^2}{4}\,\partial_r f, \quad
\mathrm{grad}_\theta = \frac{(1-r^2)^2}{4r^2}\,\partial_\theta f$$

**정보 용량에 관한 주의**: 쌍곡 부피는 반지름에 대해 지수적으로 증가하지만, 이것은 유한 비트 표현의 정보 용량과 무관하다. $b$비트 상태는 기하학과 무관하게 최대 $2^b$ 개 상태를 구분한다. 경계 근처의 부피 증가는 그 영역을 구분하는 데 필요한 좌표 정밀도의 증가와 정확히 상쇄된다. 따라서 "유한 공간에 무한 정보"라는 이전 판의 서술은 성립하지 않으며 철회한다. 푸앵카레 좌표의 실익은 정보량 증가가 아니라 7장의 컴팬딩과 스텝 제어다.

## 3. 미분의 위상-비트 표현

이 장이 본 논문의 핵심 기여다. "sin, cos 등 기본 연산을 비트화하여 순환시킨다"는 아이디어를 근사가 아닌 **정확한** 정리로 세운다.

### 3.1 미분 닫힘 함수족과 위상 이동

**정의 3.1** (원형 트랙). 생성원 $g = \sin$, 파라미터 $(A, \omega, \varphi) \in \mathbb{R}_{>0} \times \mathbb{R}_{>0} \times [0, 2\pi)$ 에 대해
$$f(t) = A \sin(\omega t + \varphi)$$

**정리 3.1** (미분의 위상 표현). 임의의 $n \ge 0$ 에 대해
$$\frac{d^n f}{dt^n} = A\,\omega^n \sin\!\left(\omega t + \varphi + n\frac{\pi}{2}\right)$$
즉 파라미터 공간 $(\log A, \varphi)$ 위에서 미분 연산자 $D$ 는 아핀 사상
$$D: (\log A,\ \varphi) \longmapsto (\log A + \log\omega,\ \varphi + \tfrac{\pi}{2} \bmod 2\pi)$$
이며, $\{D^n\}$ 은 위상 성분에서 순환군 $\mathbb{Z}/4$ 로 작용한다 (4계 도함수마다 위상이 복귀하고 진폭만 $\omega^4$ 배).

**증명**. $\frac{d}{dt}\sin(\omega t + \varphi) = \omega\cos(\omega t + \varphi) = \omega\sin(\omega t + \varphi + \pi/2)$. 귀납적으로 $n$회 적용하면 즉시 따른다. $\square$

고전적 순환 $\sin \to \cos \to -\sin \to -\cos \to \sin$ 은 $\varphi$ 에 $\pi/2$ 를 4번 더하면 $2\pi$ 가 되어 복귀하는 것과 동치다. 적분(역방향)은 $D^{-1}: \varphi \mapsto \varphi - \pi/2$, $\log A \mapsto \log A - \log\omega$ 로, 군 작용의 정확한 역원이다(적분 상수 제외).

### 3.2 양자화 위상에서의 정확성

**정의 3.2** (위상 레지스터). 위상을 $b$비트 정수로 양자화한다:
$$\varphi = \frac{2\pi q}{2^b}, \qquad q \in \mathbb{Z}/2^b\mathbb{Z}$$

**정리 3.2** (미분의 정확한 비트 표현). $4 \mid 2^b$ (즉 $b \ge 2$) 이면 $\pi/2$ 는 위상 격자에서 정확히 $2^{b-2}$ 스텝이므로, 미분의 위상 성분은
$$q \longmapsto q + 2^{b-2} \pmod{2^b}$$
인 **정수 덧셈**이다. 이 연산은 반올림 오차가 없다: 양자화 사상 $Q$ 와 미분 $D$ 는 위상 성분에서 정확히 가환한다 ($Q \circ D = D_{bit} \circ Q$).

**증명**. $\pi/2 = 2\pi \cdot 2^{b-2}/2^b$ 이 격자점이므로 자명하다. $\square$

**따름정리 3.2.1** (사분면 카운터). $q$ 의 상위 2비트 $q[b{-}1:b{-}2]$ 는 사분면(quadrant)을 나타내며, $2^{b-2}$ 덧셈은 이 2비트를 mod-4 카운터로 1 증가시키고 하위 비트를 보존한다. 즉 **Packed128의 사분면 필드는 곧 미분 차수 카운터** $n \bmod 4$ 이다. 이것이 이전 문서들의 "2비트 상태 순환"의 정확한 의미다.

진폭 성분 $\log A \mapsto \log A + \log\omega$ 는 일반 $\omega$ 에서 곱셈 1회다. $\omega$ 를 2의 거듭제곱 $2^k$ 로 제한하면 $\log_2 A$ 고정소수점 필드에 정수 $k$ 를 더하는 것으로 이것까지 정확한 비트 연산이 된다. 본 설계는 일반 $\omega$ 를 허용하고 진폭 갱신에 곱셈 1회를 지불한다.

### 3.3 쌍곡 트랙과 순환 불가능성

**정리 3.3** (쌍곡 2-순환). $g_0 = \sinh,\ g_1 = \cosh$, $f(t) = A\,g_s(\omega t + \varphi)$, $s \in \{0,1\}$ 에 대해
$$\frac{d^n f}{dt^n} = A\,\omega^n\, g_{s \oplus (n \bmod 2)}(\omega t + \varphi)$$
즉 미분은 **1비트 라벨 플립** $s \mapsto s \oplus 1$ 과 진폭 스케일이며, $\mathbb{Z}/2$ 순환이다. 위상은 불변이다.

**증명**. $\sinh' = \cosh$, $\cosh' = \sinh$ 에서 귀납. $\square$

주의: 원형 트랙과 달리 위상 이동으로 표현되지 않는다. $\sinh(u + c) = \sinh u \cosh c + \cosh u \sinh c$ 이므로 어떤 상수 $c$ 도 $\sinh' = \sinh(\cdot + c)$ 를 만족시키지 않는다. 따라서 쌍곡 트랙의 미분 상태는 위상 비트가 아니라 별도의 1비트 라벨이다. 이전 문서의 "$\sinh \to \cosh \to -\sinh \to -\cosh$ 4-순환"은 $\cosh' = +\sinh$ 이므로 성립하지 않는다(삼각함수 규칙의 잘못된 이식). 올바른 구조는 부호 없는 2-순환이다.

**정리 3.4** ($\tanh$ 의 순환 불가능성). $\tanh$ 를 포함하고 미분에 대해 닫힌 유한 함수 라벨 집합은 존재하지 않는다. 즉 어떤 유한 상태 기계도 $\tanh$ 의 미분 탑 $\{\tanh, \tanh', \tanh'', \dots\}$ 을 상태 순환으로 표현할 수 없다.

**증명**. $t = \tanh x$ 로 두면 $t' = 1 - t^2$ 이므로, $f = P(t)$ ($P$ 는 다항식) 꼴의 함수는 미분에 대해 닫혀 있다: $f' = P'(t)(1 - t^2)$. $\deg P = n \ge 1$ 이고 최고차항이 $a_n t^n$ 이면 $P'(t)(1-t^2)$ 의 최고차항은 $-n\,a_n t^{n+1}$ 로 차수가 정확히 1 증가한다. $\tanh$ 는 $\deg 1$ 이므로 $k$계 도함수는 $\deg k{+}1$ 다항식이고, 차수가 모두 다르므로 $\{\tanh^{(k)}\}_{k \ge 0}$ 는 선형 독립인 무한 집합이다. 유한 라벨 집합은 유한 차원 함수 공간만 생성하므로 이를 포함할 수 없다. $\square$

같은 논법으로 $\ln$ 트랙($\ln' = x^{-1}$, $(x^{-1})' = -x^{-2}, \dots$)도 유한 순환이 불가능하다(지수 카운터가 무한히 증가).

### 3.4 1차 미분 테이블: 역전파에 필요한 것의 전부

정리 3.4 는 시스템의 결함이 아니다. **역전파(1차 학습)는 각 기본 연산의 1차 도함수만 요구한다.** 따라서 필요한 구조는 무한 순환이 아니라 라벨 집합 $S$ 위의 미분 테이블 $d: S \to S'$ 이며, 원형/쌍곡 트랙에서는 이 테이블이 군 작용(각각 $\mathbb{Z}/4$, $\mathbb{Z}/2$)이라 $n$계 도함수까지 정확히 얻어지고, $\tanh$ 트랙에서는 한 단계 $d(\tanh) = \mathrm{sech}^2$ 로 충분하다. $\mathrm{sech}^2$ 자체의 도함수는 1차 학습에서 결코 필요하지 않다.

$\tanh$ 트랙에는 추가로 다음의 계산 지름길이 있다: $W = A\tanh(u)$ 일 때
$$\frac{\partial W}{\partial u} = A\,(1 - \tanh^2 u) = A - \frac{W^2}{A}$$
즉 **도함수를 순전파 결과값에서 FMA 2회로 얻는다.** 별도 함수 평가가 필요 없다.

### 3.5 요약: 미분 상태의 최소 구성

이상을 종합하면, 미분을 비트 연산으로 수행하는 데 필요한 최소 상태는:

| 구성 | 비트 | 작용 | 정확성 |
|---|---|---|---|
| 트랙 선택 (원형/쌍곡/tanh) | 2 | 불변 | — |
| 위상 레지스터 $q$ (원형) | $b$ | $q \mathrel{+}= 2^{b-2}$ | 정확 (정리 3.2) |
| 쌍곡 라벨 $s$ | 1 | $s \mathrel{\oplus}= 1$ | 정확 (정리 3.3) |
| 진폭 (로그 도메인) | $a$ | $+\log\omega$ | $\omega = 2^k$ 이면 정확 |

이전 구현의 11비트 사이클 필드는 이 최소 구성(트랙 2 + 사분면은 $q$ 상위 2비트에 내장 + 라벨 1)을 초과하는 부분이 모두 잉여이거나(구분 비트) 수학적 근거가 없는 것(tanh 순환 비트)이었다. 구현은 위 표의 의미론으로 재정의되어야 한다.

## 4. 128비트 상태 인코딩

### 4.1 레이아웃

$$\texttt{Packed128} = (\underbrace{\texttt{hi}}_{64b:\ 이산\ 상태}, \underbrace{\texttt{lo}}_{64b:\ 연속\ (r,\theta)})$$

**lo (연속 코어)**: $r \in [0, r_{\max}]$ (f32, 비트 [63:32]), $\theta \in [0, 2\pi)$ (f32, 비트 [31:0]). $r_{\max}$ 는 7.3절의 수치 안정성 분석으로 결정한다.

**hi (이산 상태 코어)**:

| 비트 | 폭 | 필드 | 의미 |
|---|---|---|---|
| [63:62] | 2 | $s_{trk}$ | 트랙: 00 원형, 01 쌍곡, 10 tanh, 11 예약 |
| [61:42] | 20 | $q$ | 위상 레지스터, $\varphi = 2\pi q/2^{20}$. 상위 2비트 = 사분면/미분 카운터 |
| [41:32] | 10 | $m_r$ | 반경 주파수 지수, $\omega_r = m_r\,\Delta\omega$ |
| [31:26] | 6 | $m_\psi$ | 각 파수 (정수) |
| [25] | 1 | $s_h$ | 쌍곡 라벨 (sinh/cosh) |
| [24] | 1 | $\sigma$ | 부호 |
| [23:8] | 16 | $a$ | 로그 진폭, $A = 2^{(a - 2^{15})/2^{11}}$ |
| [7:0] | 8 | — | 예약 |

합계 $2+20+10+6+1+1+16+8 = 64$ 비트. 각 파수 $m_\psi$ 가 정수인 것은 설계 선택이 아니라 **단일가 조건**이다: 가중치가 각도 $\psi$ 에 대해 일가 함수이려면 $g(m_\psi(\psi + 2\pi) + \cdot) = g(m_\psi\psi + \cdot)$, 즉 $m_\psi \in \mathbb{Z}$ 이어야 한다.

이전 판과의 차이: (i) "CORDIC 회전 시퀀스 32비트" 필드를 제거했다 — 6장에서 보이듯 평가기는 위상 레지스터로 직접 구동되며, 저장된 회전열은 표현력에 기여하지 않으면서(블록 상수 회전) 비트만 소비했다. (ii) 사분면 필드는 독립 필드가 아니라 $q$ 의 상위 2비트로 흡수되어, 미분 연산(정리 3.2)과 저장이 일원화되었다.

### 4.2 가중치 생성 모델

$B \times B$ 블록의 셀 $(i,j)$ 를 정규화 좌표로 사상한다:
$$u = \frac{2j}{B-1} - 1,\quad v = \frac{2i}{B-1} - 1,\qquad
\rho_{ij} = \min\!\big(\sqrt{u^2 + v^2},\, 1\big),\quad \psi_{ij} = \mathrm{atan2}(v, u)$$

가중치는 극좌표 조화 원자(polar harmonic atom)로 정의한다:
$$\boxed{\ W_{ij} = (-1)^\sigma A\; g_{s}\!\big(\underbrace{\omega_r\, \rho_{ij}\, d_h(r)}_{\text{반경: 쌍곡 처프}} + \underbrace{m_\psi(\psi_{ij} + \theta)}_{\text{각도: 회전 가능 조화}} + \varphi\big)\ }$$

여기서 $g_s$ 는 트랙에 따라 $\sin$, $\sinh/\cosh$, $\tanh$ 이고, $d_h(r) = 2\,\mathrm{artanh}(r)$ 이다.

설계 근거:
- **위치 반경 $\rho_{ij}$ 가 인자에 곱해진다.** 이전 판의 생성기는 CORDIC 회전이 블록 상수여서 셀의 반경 정보가 소실되고 실질 자유도가 각도 조화 하나로 붕괴하는 결함이 있었다. 위 모델은 반경-각도 2차원 변조를 모두 보존한다.
- **$d_h(r)$ 재매개화**가 푸앵카레 기하가 실제로 들어오는 지점이다: $r$ 이 유계 구간을 움직일 때 유효 반경 주파수 $\omega_r d_h(r)$ 는 $[0, \infty)$ 를 커버한다(7.1절의 정밀도 한계 내에서).
- 진폭·위상·주파수가 전부 비트 필드이므로, 3장의 미분 규칙이 이 모델에 그대로 작용한다.

표현력에 대한 정직한 서술: 이 모델은 블록당 **원자 1개**다. 임의 블록의 근사는 8장의 잔차 코딩과 결합해야 하며, 원자 $J$ 개의 중첩(비용 $128J$ 비트)은 자연스러운 확장이다.

## 5. 순전파와 역전파: 상태 위의 연쇄법칙

### 5.1 순전파

$y = Wx$ 는 블록 단위로:
$$y_i = \sum_j W_{ij}\, x_j$$
$W_{ij}$ 는 저장되지 않고 4.2의 식으로 즉석 평가된다. 셀당 비용은 인자 계산(FMA 2~3회) + 생성원 평가($C_g$, 6장) + 누적 FMA 1회다.

### 5.2 역전파: 연속 파라미터

$\delta_i = \partial L/\partial y_i$ 라 하면 표준 연쇄법칙으로
$$\frac{\partial L}{\partial W_{ij}} = \delta_i\, x_j,
\qquad
\frac{\partial L}{\partial r} = \sum_{i,j} \delta_i\, x_j\, \frac{\partial W_{ij}}{\partial r},
\qquad
\frac{\partial L}{\partial \theta} = \sum_{i,j} \delta_i\, x_j\, \frac{\partial W_{ij}}{\partial \theta}$$

(이전 판 §4.3.1 의 $x_j$ 이중 곱은 오류였으므로 정정한다.)

편미분은 해석적으로:
$$\frac{\partial W_{ij}}{\partial r} = (-1)^\sigma A\, g_s'(u_{ij})\cdot \omega_r\,\rho_{ij}\cdot \frac{2}{1-r^2},
\qquad
\frac{\partial W_{ij}}{\partial \theta} = (-1)^\sigma A\, g_s'(u_{ij})\cdot m_\psi$$

여기서 $u_{ij}$ 는 4.2의 생성원 인자이고 $d_h'(r) = 2/(1-r^2)$ 를 사용했다.

**핵심**: $g_s'(u_{ij})$ 는 3장의 상태 연산으로 얻는다 —

- 원형 트랙: 상태 사본의 위상에 $2^{18}$ 을 더하고( $b=20$ 에서 $\pi/2$ ) **같은 순전파 평가기를 재호출**한다.
- 쌍곡 트랙: 라벨 비트를 플립하고 재호출한다.
- tanh 트랙: 순전파 값 $W_{ij}$ 로부터 $A - W_{ij}^2/A$ (FMA 2회).

따라서 **그래디언트 평가 비용 = 순전파 평가 비용**이며, 미분을 위한 별도 커널·별도 근사(유한차분)가 필요 없다. 이것이 "미분의 비트화"의 계산적 내용이다.

### 5.3 역전파: 이산 상태

이산 필드($s_{trk}, m_r, m_\psi, s_h$)에 대한 손실의 변화는 미분이 아니라 **이산 전방차분**이다:
$$\Delta_h L = L(h') - L(h), \qquad h' \in N(h)$$
여기서 $N(h)$ 는 이웃 집합(예: $m_r \pm 1$, $m_\psi \pm 1$, 라벨 플립)이다. 이는 의사-불리언 최적화(pseudo-Boolean optimization; Boros & Hammer 2002)의 국소 탐색이며, 이전 문서들이 이를 "해석적 미분"이라 불렀던 것은 용어 오류이므로 정정한다.

비용을 정직하게 계상한다: $\Delta_h L$ 1회 평가 = 블록 순전파 1회 = $O(B^2 C_g)$. 따라서 이산 갱신은 매 스텝이 아니라 주기 $\tau$ 마다 수행하고, 후보 수 $|N(h)|$ 를 제한한다. 스텝당 상각 비용은 $O(B^2 C_g |N(h)|/\tau)$ 다.

수용 규칙은 메트로폴리스: $\Pr[\text{수용}] = \min(1, e^{-\Delta_h L / T_t})$. 전역 수렴 보장은 로그 냉각 $T_t \ge c/\log(1+t)$ 을 요구하며(Hajek 1988), 실용적 기하 냉각은 이 보장을 포기하는 휴리스틱임을 명시한다.

### 5.4 리만 갱신

연속 파라미터는 2장의 리만 그래디언트로 갱신한다:
$$r \leftarrow \Pi_{[0, r_{\max}]}\!\left(r - \eta\,\frac{(1-r^2)^2}{4}\,\frac{\partial L}{\partial r}\right),
\qquad
\theta \leftarrow \theta - \eta\,\frac{(1-r^2)^2}{4r^2}\,\frac{\partial L}{\partial \theta} \pmod{2\pi}$$

1차 리트랙션(투영) 대신 정확한 지수 사상 $\mathrm{Exp}_x$ (2장)를 쓸 수도 있다. 계량 인자 $(1-r^2)^2/4$ 는 $r \to 1$ 에서 스텝을 $O((1-r)^2)$ 로 감쇠시키므로, 경계 위반이 구조적으로 억제된다 — 이것이 유클리드 클리핑 대비 푸앵카레 파라미터화의 실질 이점이다. 이전 구현의 `clamp(0.1, 2.0)` 은 $r < 1$ 정의역을 위반하는 버그이므로 $\Pi_{[0, r_{\max}]}$ 로 교체되어야 한다.

**명제 5.1** (수렴, 정직한 범위). 가정: (i) 이산 갱신 스케줄이 유한 시각 $T_d$ 이후 정지한다, (ii) 고정된 이산 상태 $h^*$ 에서 $L(r, \theta; h^*)$ 는 콤팩트 집합 $\{r \le r_{\max}\}$ 위에서 $C^1$ 이고 그래디언트가 립시츠다(매끄러운 함수들의 합성이므로 성립), (iii) 스텝 크기가 Robbins–Monro 조건 $\sum\eta_t = \infty$, $\sum\eta_t^2 < \infty$ 을 만족한다. 그러면 $T_d$ 이후의 리만 확률적 경사 하강은 정류점(stationary point)으로 수렴한다 (Bonnabel 2013).

이 명제는 **전역 최적성을 주장하지 않는다**. 이전 판의 "전역 수렴 정리"들은 증명이 없거나 가정이 알고리즘과 모순되어 철회한다.

## 6. 평가기: 위상 인덱스 LUT와 CORDIC의 올바른 조건

### 6.1 사분파 LUT (권장 평가기)

위상이 이미 $b$비트 정수이므로, 자연스러운 평가기는 테이블 조회다. 사분면 대칭으로 $[0, \pi/2)$ 구간만 $2^k$ 엔트리로 저장한다:

- 인덱스: $q$ 의 상위 2비트 = 사분면(부호/반전 결정), 다음 $k$ 비트 = 테이블 인덱스, 나머지 = 선형 보간 분수.
- 보간 오차 상계: 격자 $h = (\pi/2)/2^k$ 에서 $\displaystyle \max|err| \le \frac{h^2}{8}\max|g''| = \frac{1}{8}\left(\frac{\pi}{2^{k+1}}\right)^2$ ($g = \sin$, $|g''| \le 1$).
- $k = 12$ (16 KB, L1 상주): $err \le \frac{1}{8}(\pi/2^{13})^2 \approx 1.8 \times 10^{-8}$ — f32 ULP 이하.

비용 $C_g$: 인덱스 추출(비트 연산) + 조회 2회 + 보간 FMA 1회 + 사분면 부호 적용 $\approx$ 6~10 FLOP 상당. 쌍곡·tanh 트랙은 인자가 유계이도록 필드 범위를 설계하고($|u| \le u_{\max}$), 동일한 방식의 유계 구간 테이블을 쓴다.

이 평가기의 장점은 3장과의 정합성이다: 미분(위상 $+2^{b-2}$)이 곧 테이블 인덱스의 사분면 증가이므로, **순전파와 도함수 평가가 문자 그대로 같은 코드 경로**다.

### 6.2 쌍곡 CORDIC: 올바른 조건 (대안 평가기)

하드웨어 구현에서 CORDIC 을 쓰려면 다음 표준 조건을 지켜야 한다 (Walther 1971). 이전 판은 이 전부를 누락했다.

- 반복식 (쌍곡 회전 모드): $x_{i+1} = x_i + d_i y_i 2^{-i}$, $y_{i+1} = y_i + d_i x_i 2^{-i}$, $z_{i+1} = z_i - d_i\,\mathrm{artanh}(2^{-i})$.
- 반복은 $i = 1$ 부터 시작한다 ($\mathrm{artanh}(2^0) = \infty$; $i=0$ 을 포함하면 불변량 $x^2 - y^2$ 에 인자 $1 - 2^{-0} = 0$ 이 곱해져 모든 입력이 퇴화한다).
- 수렴을 위해 인덱스 $i = 4, 13, 40, \dots$ ($i_{k+1} = 3i_k + 1$)를 반복 수행한다.
- 게인: $A_h = \prod_{i \in I}\sqrt{1 - 2^{-2i}} \approx 0.8281$ (반복 인덱스 포함 시 $\approx 0.80$). 이전 판의 $0.6073$ 은 원형 CORDIC 상수 $1/\prod\sqrt{1+2^{-2i}} = 1/1.64676$ 이며 쌍곡 게인이 아니다.
- 수렴 영역: $|z| \le \sum_{i \in I}\mathrm{artanh}(2^{-i}) \approx 1.1182$. 인자가 이를 넘으면 항등식 $\sinh(u + m\ln 2) = \frac{1}{2}(2^m e^u - 2^{-m}e^{-u})$ 류의 구간 축소가 선행되어야 한다.

본 논문은 소프트웨어 경로에서 6.1의 LUT 를 표준으로 하고, CORDIC 은 위 조건을 만족하는 경우의 하드웨어 대안으로 한정한다. 이전 판의 "CORDIC 회전 + 주기적 $\tanh$ 수축" 알고리즘은 원형 회전과 민코프스키 좌표의 혼동 위에 있었고 표현력 붕괴를 초래했으므로 폐기한다.

## 7. 푸앵카레 반경의 수치 해석

### 7.1 $d_h$ 컴팬딩과 정밀도 한계

$r$ 을 f32로 저장하고 $d_h(r) = 2\,\mathrm{artanh}(r)$ 를 사용할 때, $r$ 의 표현 오차 $\delta r$ 이 유발하는 쌍곡 거리 오차는
$$\delta d_h = \frac{2\,\delta r}{1 - r^2}$$

f32 상대 오차 $u = 2^{-24}$ 에서 $r \approx 1$ 근방 $\delta r \approx u$ 이고, $d_h \approx \ln\frac{2}{1-r}$ 이므로 $\frac{1}{1-r} \approx \frac{e^{d_h}}{2}$, 따라서
$$\delta d_h \approx u\, e^{d_h}$$

즉 목표 정밀도 $\varepsilon_d$ 에 대해 사용 가능한 쌍곡 범위는
$$d_h \le \ln\frac{\varepsilon_d}{u}$$
예: $\varepsilon_d = 10^{-3}$, f32 → $d_h \le \ln(2^{-10}/2^{-24} \cdot \tfrac{1}{1.024}) \approx 9.7$. 이것이 "유계 비트로 비유계 스케일"의 정확한 의미다: 커버리지는 무한이 아니라 **비트 수에 로그-선형으로 비례**하며, 상대 정밀도가 지수적으로 소진된다. 부동소수점 지수부와 동일한 구조의 컴팬딩이다.

### 7.2 경계 안정성: Sterbenz 보정

계량 인자와 $d_h'$ 는 $1 - r^2$ 을 포함한다. 소박한 계산 $\mathrm{fl}(1 - \mathrm{fl}(r^2))$ 은 $r \to 1$ 에서 파국적 상쇄로 상대 오차가 $u/(1-r^2)$ 까지 증폭된다(예: $r = 1 - 2^{-12}$ 에서 약 12% 오차). 다음이 해결책이다.

**명제 7.1**. $r \in [\tfrac{1}{2}, 1]$ 이면 $\mathrm{fl}(1 - r) = 1 - r$ 로 **정확**하다 (Sterbenz 보조정리: $b/2 \le a \le 2b$ 인 부동소수점 감산은 오차가 없다; $a = 1, b = r$ 에 적용). 따라서
$$1 - r^2 = (1 - r)(1 + r)$$
로 계산하면 전체 상대 오차는 $r$ 값과 무관하게 $2u + O(u^2)$ 이하다.

**증명**. $1 - r$ 은 정확, $1 + r \in [1.5, 2]$ 의 반올림 오차 $\le u$, 곱셈 반올림 $\le u$. 합성하면 $\le 2u + O(u^2)$. $\square$

이로써 경계 근처($r_{\max} = 1 - 2^{-20}$ 수준까지)에서도 계량·그래디언트 계산이 f32 로 안정적이다. 별도의 테일러 근사(이전 판 §3.6.2 — $r \approx 1$ 에서 $r = 0$ 전개를 쓰는 오류)는 불필요하며 폐기한다.

### 7.3 양자화 오차 바닥의 합성

가중치 상대 오차(진폭 $A$ 기준)를 소스별로 합성하면:

| 소스 | 상계 (본 레이아웃) |
|---|---|
| 위상 ($b = 20$) | $|g'| \cdot \Delta\varphi/2 = \pi/2^{20} \approx 3.0 \times 10^{-6}$ |
| 로그 진폭 (16비트, 스텝 $2^{1/2^{11}}$) | $\tfrac{1}{2}\ln 2/2^{11} \approx 1.7 \times 10^{-4}$ |
| LUT ($k = 12$) | $1.8 \times 10^{-8}$ |
| $r$ (f32 + Sterbenz) | $\omega_r \rho\, \delta d_h$, 7.1절 범위 내에서 $\lesssim 10^{-5}$ |

**결론**: 본 128비트 레이아웃의 RMSE 바닥은 진폭 양자화가 지배하는 $\sim 10^{-4} A$ 수준이다. 이전 판들의 "$10^{-6}$ 급(S급) 정확도" 주장은 이 레이아웃에서는 성립하지 않으며, 위상 한계 $3 \times 10^{-6}$ 까지 내리려면 진폭을 f32 로 승격한 160비트 확장이 필요하다. 정확도 주장은 반드시 이 표의 유도와 함께 제시되어야 한다.

## 8. 압축률과 왜곡: 성립 조건의 정직한 유도

### 8.1 일반 행렬에 대한 불가능성

**정리 8.1** (rate-distortion 하한). 분산 $\sigma^2$ 의 i.i.d. 가우시안 가중치 소스를 가중치당 $R$ 비트로 부호화할 때 달성 가능한 최소 왜곡은 $D(R) = \sigma^2 2^{-2R}$ 이다 (Cover & Thomas). $B = 64$ 블록을 128비트로 부호화하면 $R = 128/4096 = 1/32$ bpw 이고
$$D \ge \sigma^2\, 2^{-1/16} = 0.958\,\sigma^2 \quad\Longrightarrow\quad \mathrm{RMSE} \ge 0.979\,\sigma$$

즉 **일반(무구조) 가중치의 1024:1 압축은 "전부 0으로 치환"과 사실상 구별되지 않는 재현 품질이 정보이론적 최선**이다. 따라서 "1000:1 + 저 RMSE" 는 일반 행렬에 대해 원리적으로 불가능하며, RBE 는 범용 압축기가 아니라 **구조 가정 하의 파라메트릭 압축기**로 정의되어야 한다.

### 8.2 파라메트릭 압축기로서의 왜곡 분해

모델 다양체 $\mathcal{M} = \{W(\Theta) : \Theta \in \text{Packed128}\} \subset \mathbb{R}^{B^2}$ 에 대해, 타깃 $W^*$ 의 재현 오차는 직교 분해된다:
$$\mathrm{RMSE}^2 = \underbrace{\frac{\mathrm{dist}(W^*, \mathcal{M})^2}{B^2}}_{\text{모델 부적합(지배항)}} + \underbrace{\varepsilon_{quant}^2}_{\text{7.3절 바닥}}$$

낮은 RMSE 는 $W^*$ 가 $\mathcal{M}$ 근방에 있을 때만 가능하다. 실제 신경망 가중치가 그러한지는 **가정이 아니라 측정 대상**이다(10장).

### 8.3 잔차 코딩과 운용점

모델 부적합을 줄이는 표준 수단은 잔차 $E = W^* - W(\Theta)$ 의 변환 코딩이다. 계수 1개를 (위치 $\lceil \log_2 B^2 \rceil$ 비트 + 값 f16) 로 부호화하면 블록 비트는
$$\mathrm{bits}(B, K) = 128 + K\big(\lceil \log_2 B^2 \rceil + 16\big)$$

$B = 64$ 에서 계수당 28비트:

| $K$ | 총 비트 | 압축률 (원본 $32B^2 = 131{,}072$ 비트 대비) |
|---|---|---|
| 0 | 128 | 1024 : 1 |
| 10 | 408 | 321 : 1 |
| 50 | 1,528 | 85.8 : 1 |
| 200 | 5,728 | 22.9 : 1 |

잔차의 정렬 계수가 멱법칙 $|c_{(k)}| \le c_1 k^{-\alpha}$ ($\alpha > 1/2$) 로 감쇠하면 꼬리 에너지 적분으로
$$\mathrm{RMSE}(K) \le \frac{c_1}{\sqrt{2\alpha - 1}}\, \frac{K^{-(2\alpha-1)/2}}{B}$$
즉 **왜곡-레이트 곡선은 타깃의 스펙트럼 감쇠 $\alpha$ 가 결정**한다. $\alpha$ 는 레이어별 실측 대상이며, 압축률 주장은 반드시 $(K, \mathrm{RMSE})$ 쌍으로 보고해야 한다. 이전 판들처럼 $K$ 를 숨긴 단일 압축률 수치는 무의미하다.

주의(구현 정합): 잔차를 계산·저장하고 복원 시 버리는 현재 구현은 위 식의 어떤 운용점도 달성하지 못한다. 역변환(역DCT/역DWT)이 구현되어야 이 절이 유효하다.

### 8.4 다중 원자 확장

원자 $J$ 개의 중첩은 레이트 $J \cdot 128 / B^2$ bpw 로 매칭 퍼슈트(matching pursuit)형 인코딩이 가능하며, 잔차 코딩과 함께 3-파라미터 설계 공간 $(J, K, B)$ 을 이룬다. 최적 운용점 선택은 10장의 프로토콜로 결정한다.

## 9. 속도: 루프라인 유도

기계 모델: 피크 연산 $P$ (FLOP/s), 메모리 대역폭 $\beta$ (byte/s), 기계 균형 $I^* = P/\beta$ (FLOP/byte). 생성원 평가 비용 $C_g$ (FLOP 상당, 6장: LUT 6~10, CORDIC(20회) 약 60).

### 9.1 배치 1 (GEMV, 추론)

- 밀집: FLOP $2MN$, 가중치 트래픽 $4MN$ 바이트 → 연산 강도 $0.5 \ll I^*$ → 메모리 결박, $T_{dense} = 4MN/\beta$.
- RBE: 트래픽 $16MN/B^2$ 바이트 (블록당 16바이트; $B = 64$ 에서 밀집의 $1/1024$) → 연산 결박, $T_{rbe} = (2 + C_g)MN/P$.

**정리 9.1** (배치-1 속도비).
$$S = \frac{T_{dense}}{T_{rbe}} = \frac{4 I^*}{2 + C_g}$$
따라서 이득 조건은
$$\boxed{\ C_g < 4I^* - 2\ }$$

예시 사양 $P = 2$ TFLOP/s, $\beta = 50$ GB/s ($I^* = 40$): LUT($C_g = 8$)로 $S = 160/10 = 16$, CORDIC-20($C_g = 60$)로 $S = 160/62 \approx 2.6$. 이 수치는 상한 모델이며 실측이 아니다 — 캐시 효과, 명령 혼합, $x, y$ 트래픽을 무시했다.

### 9.2 배치 $n$ (GEMM, 학습·대배치 추론)

밀집은 가중치를 $n$ 회 재사용하므로 $T_{dense} = \frac{2MN}{P}\max(n,\, 2I^*)$. RBE 는 타일 내 가중치를 생성 후 레지스터에서 $n$ 회 재사용하면 $T_{rbe} = \frac{MN}{P}(2n + C_g)$. 따라서
$$S(n) = \frac{2\max(n,\, 2I^*)}{2n + C_g}$$

**따름정리 9.2**. $S(n) > 1 \iff n < 2I^* - C_g/2$. 대배치 극한에서 $S(n) \to \frac{2n}{2n + C_g} < 1$, 즉 **밀집 대비 최대 패리티에 점근**한다(약간 느림).

정직한 결론: RBE 의 속도 이득은 **메모리 결박 영역(소배치 추론)에 한정**되고, 그 크기는 정리 9.1 이 정확히 규정한다. 이전 판의 "faster-than-dense 달성"(무조건적)과 차원이 맞지 않는 부등식($\frac{MN \times 4}{B^2 \times 16} > C$; 좌변은 트래픽 비, 우변은 연산량 배수)은 오류이므로 위 유도로 대체한다. 대역폭 비 $B^2/4$ 는 속도비의 상한이 아니라 트래픽 절감 배수일 뿐이다.

### 9.3 미분 비용

5.2절에 의해 역전파의 $g'$ 평가는 순전파 평가기 재사용이므로, 역전파 총 비용은 순전파의 상수배($\le 3$배: $\delta$ 전파 + $\partial_r$ + $\partial_\theta$; tanh 트랙은 FMA 2회 지름길로 더 낮음)다. 이산 상태 갱신은 5.3절의 상각 비용을 따른다. "미분이 공짜"가 아니라 "**미분이 순전파와 같은 가격**"이 정확한 서술이다.

## 11. 제1부 결론

제1부는 RBE 의 수학적 기초를 오류 없는 형태로 재유도했다.

성립하는 것: (i) 미분에 닫힌 함수족에서 미분은 양자화 위상 레지스터 위의 정확한 정수 연산이다 — $\sin$ 트랙의 $\mathbb{Z}/4$, 쌍곡 트랙의 $\mathbb{Z}/2$ 순환은 근사가 아니라 정리다. (ii) 그래디언트 평가는 위상을 이동한 순전파 재사용으로, 미분 비용이 순전파와 같아진다. (iii) 푸앵카레 반경 재매개화는 로그-선형 스케일 커버리지와 경계 자동 감쇠라는 계량 가능한 이점을 준다. (iv) 소배치 추론에서 속도 이득 조건은 $C_g < 4I^* - 2$ 로 정확히 규정된다.

성립하지 않아 철회한 것: 유한 비트의 무한 정보 저장, $\tanh$ 를 포함한 4-순환, 일반 행렬의 1000:1 저손실 압축, 무조건적 faster-than-dense, 전역 수렴 정리, 그리고 이전 판의 모든 미실측 실험 수치.

남는 과학적 질문은 하나다: **실제 신경망 가중치가 극좌표 조화 원자 다양체에 얼마나 가까운가.** 이것은 이론이 아니라 10장의 측정이 답할 문제이며, 본 프레임워크의 가치는 그 답이 어떤 것이든 왜곡-레이트-속도 3면의 운용점을 정확히 계량할 수 있게 되었다는 데 있다.

# 제2부: 평면 압축 이론 — 가중치장으로서의 RBE

제1부는 "주어진 행렬을 근사한다"는 문제 설정 아래에서 한계(정리 8.1)를 유도했다. 제2부는 문제 설정 자체를 교체한다. **RBE 가 저장하는 대상은 $B^2$ 개 표본이 아니라 평면 위의 연속 함수 $W: \mathbb{D} \to \mathbb{R}$ 이며, 표본은 그 함수를 임의 해상도로 읽은 것에 불과하다.** 이 관점에서 압축률·미분·기저의 이론이 어떻게 달라지는지 유도한다.

## 12. 대상의 재정의: 표본 압축이 아니라 장의 부호화

### 12.1 두 문제의 분리

- **문제 A (행렬 압축)**: 주어진 $W^* \in \mathbb{R}^{B^2}$ 를 적은 비트로 근사. 정리 8.1 이 지배하며, 소스가 무구조이면 가중치당 비트가 왜곡을 결정한다.
- **문제 B (장 부호화)**: 연속 장 $W: \mathbb{D} \to \mathbb{R}$ 를 부호화하고, 필요할 때 임의 격자에서 표본화. 정보량은 **장 클래스의 복잡도**가 결정하며 해상도 $B$ 와 무관하다.

RBE 의 생성 모델(4.2절)은 애초에 연속 $(u, v)$ 의 닫힌형 함수이므로 문제 B 의 부호기다. 제1부에서 문제 A 의 잣대를 들이댄 것은 사전학습 가중치 근사라는 용도에 대해서였고 그 결론(불가능)은 유지되지만, 문제 B 로서의 RBE 에는 다른 이론이 적용된다.

### 12.2 ε-엔트로피: 해상도는 정보가 아니다

**사실 12.1** (Kolmogorov–Tikhomirov). 2차원 정의역 위 함수 클래스의 ε-엔트로피(ε-정확도 표현에 필요한 최소 비트)는
- Sobolev 급 $s$-매끄러움: $H_\varepsilon \asymp \varepsilon^{-2/s}$
- 해석적(analytic) 함수: $H_\varepsilon \asymp (\log 1/\varepsilon)^{3}$

어느 쪽이든 **$B$ 가 등장하지 않는다.** 따라서 장 부호화의 압축률
$$C(B) = \frac{32 B^2}{\mathrm{bits}} \xrightarrow{B \to \infty} \infty$$
는 정보이론 위반이 아니라, 분모(장의 정보)가 유한한데 분자(표본 수)가 임의로 커질 수 있다는 자명한 사실의 표현이다. 이전 판들의 "무한 정보" 직관의 올바른 형태가 이것이다: **정보는 유계, 해상도는 무계.** 128비트 원자는 해석적 장이므로 사실 12.1 의 둘째 경우에 속하며, $J$ 개 원자·잔차 $K$ 개는 그 계수의 상수를 조정한다.

### 12.3 해상도 불변성과 탄력 배포

원자가 닫힌형 함수이므로 다음이 정의에서 즉시 따른다.

**명제 12.2** (이산화 불변성). 하나의 코드 $\Theta$ 는 모든 해상도 $B$ 에서 일관된 표본 $W_{ij} = W(u_i, v_j; \Theta)$ 을 제공하며, $B \to \infty$ 에서 층은 적분 작용소 $(\mathcal{W}x)(u) = \int W(u,v)\,x(v)\,dv$ 로 수렴한다. $s$-매끄러운 장의 리만 합 오차는 $O(B^{-s})$ 다.

이는 신경 연산자(neural operator) 문헌에서 "discretization invariance" 라 부르는 성질이며(Kovachki et al. 2021), 밀집 행렬·INT4 양자화에는 원리적으로 존재하지 않는 축이다. 실용적 귀결은 **탄력 해상도 배포**다: 한 벌의 코드로 기기 성능에 따라 층 폭을 골라 표본화하는 배포가 가능하다(코드 재학습 없음). 이 주장의 검증은 15장 프로토콜 3 이다.

### 12.4 적용 가능 조건 (정직한 경계)

장 관점이 성립하려면 **가중치 인덱스 공간에 기하가 있어야 한다.** 대상별로:

| 대상 | 인덱스 기하 | 장 관점 |
|---|---|---|
| 합성곱 커널 $(dx, dy)$ | 평면 이동 | 자연 성립 |
| 연산자 커널 (PDE, 물리 정의역) | 물리 좌표 | 자연 성립 (신경 연산자의 전제) |
| 상대 위치 구조 (RoPE, ALiBi) | 1차원 거리 | 자연 성립 — RoPE 는 문자 그대로 위상 장 $e^{i m\theta_j}$ |
| 어텐션 $QK^\top$ 의 위치 성분 | 시퀀스 좌표 | 부분 성립 |
| MLP 은닉 유닛 간 가중치 | **순열 대칭 — 고정 기하 없음** | 격자 좌표로는 불성립. **잠재 좌표를 함께 학습하는 레이어 단위 부호화(15장)로 조건부 성립** |

마지막 행의 해결책이 16장의 주제이며, 앞의 세 행은 좌표 학습 없이도 즉시 착수 가능한 자연 표적이다.

## 13. 쌍곡 평면파 원자: 평면 압축의 올바른 기저

### 13.1 왜 쌍곡 평면인가: 위치-스케일 공간과의 동일시

1차원 연속 웨이블릿 변환(CWT)의 파라미터 공간은 (위치 $b$, 스케일 $a > 0$)의 상반평면이고, 아핀 군 $x \mapsto ax + b$ 의 불변 계량은
$$ds^2 = \frac{db^2 + da^2}{a^2}$$
— 곡률 $-1$ 의 **쌍곡 평면 그 자체**다 (Grossmann–Morlet 1984 이래 표준 사실; coorbit 이론의 기하학적 배경). 따라서 푸앵카레 원판 위에 정의된 장은 등거리 동형을 통해 **위치-스케일 공간 위의 장**이다.

"평면 자체를 압축한다"는 주장의 수학적 내용이 이것이다: 쌍곡 평면의 장을 소수의 스펙트럼 원자로 부호화하는 것은 **한 신호의 모든 스케일 성분(웨이블릿 계수 장)을 통째로 파라메트릭하게 압축**하는 것과 같다. 유클리드 푸리에 모드가 단일 스케일 진동이라면, 쌍곡 모드는 스케일 축을 내장한 다중스케일 원자다.

### 13.2 Busemann 좌표와 쌍곡 평면파

경계점 $b \in \partial\mathbb{D}$ ($|b| = 1$)에 대해 푸아송 핵과 Busemann 좌표를 정의한다:
$$P(z, b) = \frac{1 - |z|^2}{|z - b|^2}, \qquad B_b(z) = \log P(z, b)$$

**명제 13.1** (Busemann 좌표의 성질).
1. $b = 1$, $z = r$ (실축) 에서 $P = \frac{(1-r^2)}{(1-r)^2} = \frac{1+r}{1-r}$ 이므로 $B_b(r) = \ln\frac{1+r}{1-r} = d_h(r)$. 즉 **$B_b$ 는 $b$ 방향 측지선을 따라 정확히 쌍곡 호장(弧長)이다** — 제1부의 $d_h$ 재매개화(7.1절)는 이 좌표의 라디얼 단면이었다.
2. $\|\nabla B_b\|_{hyp} = 1$ (단위 기울기), $B_b$ 의 등위선은 $b$ 에 접하는 수평원(horocycle)이다.
3. 계산 비용: $|z - b|^2 = 1 + r^2 - 2r\cos(\theta - \theta_b)$ 이므로 $B_b$ 는 cos LUT 1회 + log LUT 1회 + FMA 수 회로 평가된다.

**정의 13.1** (쌍곡 평면파 원자). $\rho = \tfrac{1}{2}$ (H² 의 스펙트럼 상수), 스펙트럼 파라미터 $\lambda \ge 0$, 위상 $\varphi$, 진폭 $A$ 에 대해
$$W(z) = A\; e^{\rho B_b(z)}\, \cos\!\big(\lambda\, B_b(z) + \varphi\big)$$

이는 Helgason 평면파 $e^{(\rho + i\lambda)B_b(z)}$ 의 실수형이며, 쌍곡 라플라시안의 고유함수다: $\Delta_{\mathbb{H}}\, e^{(\rho+i\lambda)B_b} = -(\lambda^2 + \rho^2)\, e^{(\rho+i\lambda)B_b}$ (부호 규약은 Helgason 1984 따름). $b$ 방향으로 진동하고 수평원 위에서 상수인, 쌍곡 평면의 "평면파"다. 성장 인자 $e^{\rho B}$ 는 $b$ 쪽으로 증가하지만 작업 영역 $r \le r_{\max}$ 에서 유계다.

**비트 인코딩**: 원자 파라미터는 $(\theta_b, \lambda, \varphi, \log A)$ — 방향 12비트, 스펙트럼 12비트, 위상 레지스터 20비트, 로그 진폭 16비트로 4.1절과 동일한 예산에 담긴다. 4.2절의 극좌표 원자는 이 구성의 임시 형태였으며, 정의 13.1 이 그것을 대체하는 **기하학적으로 올바른 원자**다.

**뫼비우스 평행이동과 lo 필드**: 연속 파라미터 $(r, \theta)$ 는 원자의 뫼비우스 평행이동 $W \mapsto W \circ g^{-1}_{(r,\theta)}$ 로 해석된다. Helgason 항등식에 의해 평행이동된 평면파는 다시 평면파이고 $(b, \varphi, \log A)$ 의 재작성으로 닫힌다(경계점은 뫼비우스 작용으로 이동, 위상·진폭은 코사이클 항 $B_{g(b)}(g(o))$ 만큼 이동). 즉 2장의 자이로 연산이 원자 파라미터 공간 위의 정확한 군 작용으로 처음으로 실질적 역할을 얻는다.

### 13.3 일반화 위상-이동 미분 정리

**정리 13.2** (미분의 원자별 위상 이동). $t$ 를 $b$ 방향 측지 호장이라 하면 ($dB_b/dt = 1$),
$$\frac{\partial W}{\partial t} = A\sqrt{\rho^2 + \lambda^2}\;\, e^{\rho B_b}\cos\!\big(\lambda B_b + \varphi + \delta\big),
\qquad \delta = \mathrm{atan2}(\lambda, \rho)$$
즉 측지 방향 미분은 파라미터 공간의 아핀 사상
$$D_t: (\log A, \varphi) \longmapsto \big(\log A + \tfrac{1}{2}\log(\rho^2 + \lambda^2),\ \varphi + \delta\big)$$
이며, $n$계 도함수는 진폭 $\times(\rho^2+\lambda^2)^{n/2}$, 위상 $+n\delta$ 다.

**증명**. $\partial_t[e^{\rho B}\cos(\lambda B + \varphi)] = e^{\rho B}[\rho\cos(\lambda B + \varphi) - \lambda\sin(\lambda B + \varphi)]$ 이고, $\rho\cos u - \lambda\sin u = \sqrt{\rho^2+\lambda^2}\,\cos(u + \mathrm{atan2}(\lambda,\rho))$ 는 코사인 합성 항등식이다. $B$ 의 단위 기울기(명제 13.1-2)로 호장 미분과 $B$-미분이 일치한다. $\square$

**따름정리 13.2.1** (비트 구현). $\delta$ 는 원자 상수이므로 인코딩 시 1회 위상 격자로 양자화해 $q_\delta = \mathrm{round}(2^b \delta / 2\pi)$ 로 저장한다. 이후 모든 미분은
$$q \mathrel{+}= q_\delta \pmod{2^b}$$
인 정수 덧셈이며, $n$계 미분은 $q \mathrel{+}= n\,q_\delta$ 다. 저장된 $q_\delta$ 에 대해 반복 미분은 정확하다(오차는 최초 양자화 $\le \pi/2^b$ 1회뿐, 차수에 따라 누적되지 않음 — 위상 오차는 $n$ 에 대해 선형이지만 $n q_\delta$ 를 한 번에 더하면 1회 반올림으로 고정).

**따름정리 13.2.2** (제1부와의 통일). $\rho \to 0$ (유클리드 극한)에서 $\delta \to \pi/2$, $\sqrt{\rho^2+\lambda^2} \to \lambda$ 로 정리 3.1–3.2 가 복원된다. 원형 트랙의 $\mathbb{Z}/4$ 순환은 쌍곡 평면파 미분의 특수경우다.

### 13.4 완비성, 대역 제한, 표본화

**사실 13.3** (Helgason 역변환). $L^2(\mathbb{D}, d\mu_{hyp})$ 의 임의의 장은 평면파의 스펙트럼 적분
$$f(z) = \frac{1}{4\pi}\int_0^\infty \int_{\partial\mathbb{D}} \hat f(\lambda, b)\, e^{(\rho + i\lambda)B_b(z)}\, |c(\lambda)|^{-2}\, db\, d\lambda$$
로 표현된다 ($c$ 는 Harish-Chandra c-함수; Helgason 1984). 따라서 유한 원자 합 $\sum_{j=1}^J A_j e^{\rho B_{b_j}}\cos(\lambda_j B_{b_j} + \varphi_j)$ 은 절단 스펙트럼 표현이고, 원자 수 $J$ 를 늘리면 임의 장에 수렴한다 — **4.2절의 "원자 1개" 표현력 한계는 원자족의 한계가 아니라 절단의 한계**임이 이로써 명확해진다. 이산 원자계의 프레임 구성은 coorbit 이론(Feichtinger–Gröchenig 1989)이 제공한다.

**대역-해상도 관계**: 대역 제한 $\lambda \le \Lambda$ 인 장을 $B \times B$ 격자에서 별칭 없이 표본화하려면 Weyl 점근(고유값 밀도 $\propto$ 면적 $\times \lambda$)에 따라 $\Lambda = O(B)$ 이어야 한다. 이것이 "해상도 무계, 정보 유계"의 정량형이다: 코드가 담는 대역이 $\Lambda$ 면, $B > c\Lambda$ 이상의 해상도는 새 정보 없이 표본만 늘린다.

## 14. 무엇이 가능해지는가: 경쟁 지형의 재평가

제1부 8–9장의 결론(사전학습 일반 행렬 대체 불가, 소배치 추론 수 배)은 유지된다. 장 관점이 새로 여는 축은 다음과 같다.

### 14.1 연산자 학습: 쌍곡 스펙트럼 신경 연산자

Fourier Neural Operator(FNO; Li et al. 2021)는 커널 장을 유클리드 푸리에 모드 $K$ 개로 파라미터화한다 — 즉 FNO 는 이미 "평면 압축" 패러다임의 성공 사례다. RBE-H(정의 13.1)는 같은 프로그램의 **쌍곡 스펙트럼판**이며, 13.1절의 동일시에 의해 원자가 스케일-국소적(웨이블릿형)이다. 검증 가능한 가설: 경계층·난류처럼 스케일 계층을 갖는 커널에서, 같은 비트 예산의 쌍곡 모드가 유클리드 모드보다 낮은 왜곡을 준다. 이는 15장 프로토콜 2 의 A/B 실험으로 판정된다.

### 14.2 탄력 해상도 배포

명제 12.2 에 의해 한 벌의 코드가 모든 층 폭을 서빙한다. 양자화(INT4)·저랭크·코드북 등 표본 공간 기법에는 없는 축이며, 엣지-클라우드 공용 모델 배포의 실질 시나리오가 있다. 비용은 왜곡-레이트 곡선(8.3절)이 그 해상도 계열 전체에서 유지되는지의 검증(프로토콜 3)이다.

### 14.3 위상 장이 이미 존재하는 곳

RoPE(Su et al. 2021)는 위치 $m$, 채널 $j$ 에 대해 회전 $e^{i m \theta_j}$ 를 곱한다 — **신경망 실무에 이미 배치된 문자 그대로의 위상 장**이다. 위상-비트 미분(정리 3.2, 13.2)은 이런 구조에 native 하며, 상대 위치 커널의 장 부호화는 12.4 표의 자연 표적 중 구현 거리가 가장 짧다.

### 14.4 고계 미분 응용과의 결합

제1부 3장의 결론(PINN/INR 에서 차수 무관 $O(1)$ 정확 미분)은 장 관점에서 강화된다: 물리 정의역 위의 연산자 커널은 장이고, PDE 잔차 손실은 커널의 고계 도함수를 요구하며, 정리 13.2 가 그것을 원자당 정수 덧셈으로 준다.

## 15. 레이어 단위 부호화: 잠재 좌표와 커널 장

블록 분할은 행렬 압축 문제의 인공물이었다. 장 관점의 자연스러운 단위는 블록이 아니라 **층 전체**다. 이 장은 층 하나를 통째로 하나의 부호로 만드는 구성을 유도한다.

### 15.1 전층 스펙트럼 절단

층의 가중치 장을 블록별 원자가 아니라 전역 지지(support)를 갖는 원자 $J$ 개의 합으로 부호화한다. 레이트는 $J \cdot 128 / MN$ bpw 로 층 크기와 독립적으로 조절되고, 13.4절의 완비성이 $J \to \infty$ 수렴을 보장한다. 블록 경계 아티팩트와 블록별 메타데이터가 함께 사라진다.

### 15.2 잠재 좌표: 교환가능 배열의 표현 정리

12.4절의 장애 — MLP 인덱스의 순열 대칭 — 는 좌표를 **학습**함으로써 해소되며, 이는 임시방편이 아니라 표현 정리에 근거한다.

**사실 15.1** (Aldous–Hoover). 행·열 순열에 대해 분포가 불변인(교환가능) 무작위 배열 $W_{ij}$ 는
$$W_{ij} = f(z_i,\, w_j,\, \varepsilon_{ij})$$
꼴로 표현된다 — 잠재 위치 $z_i, w_j$, 이변수 함수 $f$, 잔차 잡음 $\varepsilon_{ij}$ (Aldous 1981; Hoover 1979; 그래폰 이론, Lovász 2012).

즉 "인덱스에 기하가 없다"는 것은 기하가 **주어지지 않았다**는 뜻이지 존재할 수 없다는 뜻이 아니며, 순열 대칭은 표현의 게이지 자유도가 된다. 층 부호화는 다음 세 성분이다:
$$\text{층} \;=\; \underbrace{\{z_i\}_{i=1}^M,\ \{w_j\}_{j=1}^N \subset \mathbb{D}}_{\text{뉴런 잠재 좌표}} \;+\; \underbrace{K(\cdot,\cdot)\ (J\ \text{원자})}_{\text{커널 장}} \;+\; \underbrace{\varepsilon}_{\text{잔차 코딩}}$$

잠재 공간으로 쌍곡 원판을 쓰는 근거: 척도 없는(scale-free)·계층적 구조를 갖는 행렬은 쌍곡 잠재 기하로 적은 파라미터에 표현된다는 복잡계 네트워크 이론의 결과(Krioukov et al. 2010)와, 학습된 가중치 행렬의 스펙트럼이 중꼬리(heavy-tailed)라는 실증(Martin & Mahoney 2021)이 있다. 이는 가설이며 판정은 16장 프로토콜 7 이다.

### 15.3 원자: Busemann 차 평면파

커널 원자를 두 좌표의 **상대** Busemann 좌표로 정의한다:
$$K(z, w) \;=\; \sum_{j=1}^{J} A_j \cos\!\big(\lambda_j\,[B_{b_j}(z) - B_{b_j}(w)] + \varphi_j\big)$$

- 이는 13.2절 평면파의 2점 형태이며, 1차원 유클리드 극한에서 $\cos((m-n)\theta)$ — **RoPE 의 상대 위치 커널** — 로 퇴화한다. 즉 RoPE 는 이 구성의 알려진 특수경우다.
- 대칭 양의정부호 커널이 필요하면 동경(zonal) 부분경우 $k(d(z,w)) = \sum_j A_j\,\varphi_{\lambda_j}(d(z,w))$ (구면 함수 전개; Godement–Gangolli 정리)를 쓴다.
- 각 인자에 대한 미분은 정리 13.2 가 그대로 적용된다: $z$ 방향 도함수 = 위상 $+\delta_j$, $w$ 방향 = 위상 $-\delta_j$.

### 15.4 분리 항등식: 묶인 고랭크 인수분해

**명제 15.2** (원자의 분리성). 코사인 차 항등식 $\cos(a - b + \varphi) = \cos(a+\varphi)\cos b + \sin(a+\varphi)\sin b$ 에 의해 각 원자는 랭크 2 로 분리된다. 따라서 $J$ 원자 커널은
$$W = F_{out}\, F_{in}^\top, \qquad F_{out} \in \mathbb{R}^{M \times 2J},\ F_{in} \in \mathbb{R}^{N \times 2J}$$
$$F_{out}[i, 2j{:}2j{+}1] = A_j\big(\cos(\lambda_j B_{b_j}(z_i) + \varphi_j),\ \sin(\lambda_j B_{b_j}(z_i) + \varphi_j)\big), \quad F_{in}[k, 2j{:}2j{+}1] = \big(\cos \lambda_j B_{b_j}(w_k),\ \sin \lambda_j B_{b_j}(w_k)\big)$$

즉 층은 **랭크 $2J$ 인수분해인데, 인수 행렬이 자유 파라미터가 아니라 $(M{+}N)$ 개 좌표와 $J$ 개 원자에서 생성되는 묶인(tied) 인수**다. 순전파는 $y = F_{out}(F_{in}^\top x)$ 로 계산하며, $F$ 를 캐시하면 압축이 무의미해지므로($2J(M{+}N)$ f32 는 밀집보다 클 수 있음) 매 토큰 재생성한다.

**비용 산수** (kogpt2 FFN, $3072 \times 768$, $J = 512$): 특징 생성 $(M{+}N) \cdot J \cdot {\sim}10 \approx 19.7$M FLOP + 인수 GEMV $2J(2M{+}2N)... = 7.9$M FLOP $\approx 27.6$M FLOP. 밀집은 $4.7$M FLOP 이지만 $9.4$MB 읽기. 예시 사양(2 TFLOP/s, 50 GB/s)에서 밀집 $189\,\mu s$ (대역폭 결박) 대 본 방식 ${\sim}14\,\mu s$ (연산 결박) — 정리 9.1 의 메모리 결박 이득이 층 단위에서도 유지되고, $J$ 가 연산-압축 균형의 손잡이다.

### 15.5 비트 회계와 핵심 대결: 자유 저랭크 대 묶인 고랭크

$$\mathrm{bits} = (M{+}N)\cdot c_z + J \cdot 128 + (\text{잔차}), \qquad c_z = 32\ (\text{좌표 } r, \theta\ \text{각 16비트})$$

예 (kogpt2 FFN): $3840 \times 32 + 512 \times 128 = 188{,}416$ 비트 $\approx 23.6$ KB 대 밀집 $9.4$ MB → **약 400:1**. 같은 비트 예산의 자유 저랭크(f16 SVD 인수)는 $r = 188{,}416 / (3840 \cdot 16) \approx 3$ 이다. 따라서 등비트 대결은:

$$\text{자유 랭크 } 3 \quad \text{대} \quad \text{묶인 랭크 } 2J = 1024$$

실제 층의 특이값 감쇠가 느릴수록(중꼬리 스펙트럼) 자유 저랭크의 비트 효율이 나빠지므로 묶인 고랭크에 승산이 있다는 것이 본 구성의 핵심 가설이다. 반대 방향의 힘은 묶인 인수의 표현력 제약이며, 어느 쪽이 이기는지는 이론이 아니라 16장 프로토콜 7 의 실측만이 판정한다.

### 15.6 좌표 학습: 리만 기하의 실제 역할

손실의 좌표 그래디언트는 원자의 공간 도함수이므로 정리 13.2 에 의해 **위상 이동된 같은 평가기**로 계산되고, 좌표 갱신은 2장의 리만 그래디언트·지수 사상으로 수행한다. 계량 인자의 경계 감쇠(5.4절)가 좌표를 원판 내부에 자동 유지한다. 리만 Adam(Bécigneul & Ganea 2019)의 이 체계에서의 실제 임무는 블록 파라미터가 아니라 **뉴런 좌표 임베딩**이다 — Nickel–Kiela 계층 임베딩과 동일한 계산 구조다.

인코딩은 교대 최적화다: (a) 좌표에 대한 리만 SGD, (b) 잔차에 대한 원자 매칭 퍼슈트($b, \lambda$ 격자 탐색 + $A, \varphi$ 최소자승), (c) 최종 잔차의 변환 코딩. 비용은 스텝당 $O((M{+}N)J)$ 이며 5.3절의 상각 원칙을 따른다.

### 15.7 확장, 게이지, 트레이드오프

- **층군 공유**: 어텐션의 $Q, K, V, O$ 네 장은 같은 잔차 스트림 좌표 $\{z_i\}$ 를 공유할 수 있다 — 좌표 1벌 + 장 4벌로 층 전체가 부호화되고, 좌표 비용이 상각된다.
- **게이지 고정**: 뫼비우스 등거리 작용은 표현을 바꾸지 않으므로($K$ 를 함께 변환하면) 좌표에 게이지 자유도가 있다. 무게중심 원점 고정 등 정규화가 필요하다.
- **탄력성 트레이드오프**: 자유 학습 좌표는 12.3절의 탄력 해상도를 잃는다(새 뉴런의 좌표가 미정의). 격자 좌표는 탄력성을 유지하되 적합도를 잃는다. 두 운용점은 용도에 따라 선택한다.

## 16. 연구 프로그램: 가능하게 만들기 위한 실험 순서

각 항목은 선행 항목의 결과에 조건부이며, 전부 실측으로만 판정한다 (CLAUDE.md 검증 기준).

1. **원자 적합성 실측 (native 표적부터)**: 학습된 CNN 커널 장, RoPE/상대위치 구조, kogpt2 어텐션의 위치 성분에 대해 $J$-원자 절단의 $\mathrm{dist}(W^*, \mathcal{M}_J)$ 감쇠 곡선을 측정한다. 이 곡선이 유클리드 DCT 절단보다 빠르게 감쇠하는 대상이 하나라도 있는지가 1차 관문이다.
2. **쌍곡 vs 유클리드 스펙트럼 A/B**: 표준 연산자 학습 벤치마크(Burgers, Darcy, Navier–Stokes)에서 FNO 의 푸리에 모드를 동일 비트 예산의 쌍곡 원자로 교체하고 해상도별 오차를 비교한다. 14.1 가설의 직접 판정.
3. **탄력 해상도**: $B = 64$ 에서 적합한 코드를 $B \in \{16, 32, 128, 256, 512\}$ 에서 제로샷 표본화, 오차의 $O(B^{-s})$ 스케일링(명제 12.2)을 확인한다.
4. **위상-비트 미분 실측**: 정리 13.2 도함수를 f64 자동미분과 대조(상대 오차, 차수 1–4), 차수당 비용 평탄성을 측정한다. PINN 소형 문제(1D 파동/열 방정식)에서 학습 시간 비교.
5. **처음부터 장-사전 학습**: 소형 트랜스포머의 FFN/합성곱 층을 $J$-원자 장 층으로 치환하고 kogpt2 증류로 품질-비트 곡선을 얻는다 (저장소 NLP 검증 규칙과 접속).
6. **왜곡-레이트-해상도 3면 보고**: 이상 결과를 $(J, K, B)$ 격자에서 통합 보고하고 8.3절·12.2절 이론 곡선과 대조한다.

7. **레이어 통짜 부호화 대 저랭크 (결정 실험)**: kogpt2 의 FFN 층 하나를 15장의 잠재 좌표 + 원자 모델로 적합하고, **같은 비트 예산의 저랭크(SVD) + 양자화 기준선**과 RMSE·다운스트림 perplexity 를 비교한다. 15.5절의 산수로는 같은 비트에서 자유 랭크 $r \approx 3$ 대 묶인 랭크 $2J \approx 1024$ 의 대결이며, 실제 층의 스펙트럼 감쇠가 느릴수록(중꼬리) 묶인 고랭크가 유리하다는 것이 검증 대상 가설이다.

1번이 실패하면(모든 대상에서 DCT 보다 느린 감쇠) 원자족 재설계로 회귀하고, 2번이 실패하면 쌍곡 스펙트럼 주장을 철회하고 유클리드 극한($\rho = 0$)으로 단순화한다. 7번이 실패하면(등비트 저랭크에 전패) 레이어 단위 주장을 철회하고 native 기하 표적(합성곱·연산자·RoPE)으로 범위를 좁힌다 — 실패 조건을 미리 명시해 둔다.

## 17. 이론 스펙 시트: 정확도-압축-속도의 달성 가능 운용점

설계 목표 "정확도 최대 보존, 속도·압축률 최대"를 이론이 허용하는 정확한 수치로 환산한다. 기준 층은 kogpt2 FFN $3072 \times 768$ ($N_w = 2{,}359{,}296$ 가중치, f32 9.44 MB)이다.

### 17.1 오차의 3원천 분해

$$\varepsilon_{total}^2 \;=\; \underbrace{\varepsilon_{misfit}^2}_{\text{원자가 못 잡는 구조}} \;+\; \underbrace{\varepsilon_{code}^2}_{\text{원자 양자화 바닥}} \;+\; \underbrace{\varepsilon_{res}^2}_{\text{잔차 양자화}}$$

- $\varepsilon_{code}$: 7.3절에서 유도된 상수 — 128비트 원자에서 $1.7\times10^{-4}$ (로그 진폭 지배), 160비트 확장(진폭 f32)에서 $3\times10^{-6}$ (위상 한계).
- $\varepsilon_{res}$: 잔차를 $b$ bpw 로 양자화할 때 Lloyd–Max(가우시안) 값 — $b{=}1$: $0.603\,\sigma_{res}$, $b{=}2$: $0.343\,\sigma_{res}$, $b{=}3$: $0.186\,\sigma_{res}$, $b{=}4$: $0.098\,\sigma_{res}$.
- $\varepsilon_{misfit}$: 원자 $J$ 개가 잡는 에너지 비율을 $c$ 라 하면 $\sigma_{res} = \sigma\sqrt{1-c}$. $c$ 는 이론이 정하지 못하는 유일한 자유 변수이며 층별 실측 대상이다(16장 프로토콜 7).

### 17.2 구조 제거의 손익분기 — 원자는 0.08 bpw 다

층 단위 부호(15.5절)의 비용은 좌표 + 원자 $= 188{,}416$ 비트 $= \mathbf{0.080}$ **bpw** 에 불과하다 (묶인 랭크 1024의 가격). 분산 축소가 잔차 부호화에서 절약하는 레이트는 $\Delta R = \tfrac12\log_2\tfrac{1}{1-c}$ bpw 이므로 손익분기는
$$\tfrac12\log_2\tfrac{1}{1-c} = 0.080 \;\Longleftrightarrow\; c = 1 - 2^{-0.16} \approx \mathbf{10.5\%}$$

**원자가 층 에너지의 10.5% 이상만 잡으면 순수 양자화보다 이득**이다 — 매우 낮은 관문이며, 이것이 이 구조의 이론적 존재 이유다.

### 17.3 운용점별 정확한 수치

그룹 스케일 오버헤드(그룹 128, f16 스케일 = 0.125 bpw)를 양쪽 모두에 포함한다.

| 운용점 | 구성 | bpw | 압축률 | 상대 RMSE (이론) | 조건 |
|---|---|---|---|---|---|
| R0 장(field) 전용 | 원자만, 타깃이 다양체 위 | $128/B^2 \to 0$ | **1024:1+ (해상도 무계)** | $1.7\times10^{-4}$ (160b: $3\times10^{-6}$) | conv 커널·RoPE·연산자 커널 등 native 장 |
| R3 극한 | 좌표+원자만 | 0.08 | **400:1** | $\sqrt{1-c}$ — 전적으로 $c$ | 저랭크 대결(프로토콜 7)로 판정 |
| R2a 균형 | 원자 + 잔차 2비트 | 2.21 | **14.5:1** | $0.343\sqrt{1-c}$ | $c{=}0.9$ 시 $0.108$ ≈ INT4 급 |
| R2b 품질 | 원자 + 잔차 3비트 | 3.21 | **10.0:1** | $0.186\sqrt{1-c}$ | $c{=}0.5$ 시 $0.131$, $c{=}0.75$ 시 $0.093$ < INT4 |
| 기준: INT4 | 그룹 양자화만 | 4.13 | 7.8:1 | $0.098$ | — |

읽는 법: **INT4 동급 정확도($\approx 0.10\,\sigma$)를 달성하는 압축률**이 $c$ 의 함수다 —
$$c = 0 \Rightarrow 7.8{:}1 \quad|\quad c = 0.5 \Rightarrow {\sim}10{:}1 \quad|\quad c = 0.75 \Rightarrow {\sim}12{:}1 \quad|\quad c = 0.9 \Rightarrow {\sim}15{:}1$$

표의 상대 RMSE 는 잔차 가우시안 가정 하의 값이다. 실측 잔차의 초과첨도 $\kappa \ne 0$ 이면 부록 D.3 의 1차 보정 $D(\kappa) = D_\varphi + \kappa D'$ 를 적용한다 (실층 검증에서 이 보정이 요구됨 — D.3 실증 참조).

정확도-속도-압축을 동시에 요구하는 목표의 이론 최적점은 **R2 하이브리드**(원자가 구조를 제거하고, 백색화된 잔차를 저비트 양자화)다. 구조적(스펙트럼 절단) 오차는 방향을 제거해 하류 품질에 해롭고 백색 오차는 관대하게 흡수된다는 것이 양자화 문헌의 일관된 관찰이므로, 원자로 구조를 빼고 잔차를 백색으로 만드는 순서가 정확도 보존에 유리하다.

### 17.4 속도의 정확한 식과 수치

배치 1 에서 $S = \min\big(\text{트래픽 비},\; \dfrac{4I^*}{2 + C_{eff}}\big)$, $C_{eff}$ = 가중치당 유효 생성 비용.

| 운용점 | 트래픽 | 가중치당 FLOP | 예시 CPU ($I^*{=}40$) | 예시 GPU FP32 ($I^*{\approx}13$) |
|---|---|---|---|---|
| 밀집 f32 | 9.44 MB | 2 | $189\,\mu s$ (기준) | $6.1\,\mu s$ (기준) |
| R3 (원자만) | 23.6 KB | ${\sim}11.7$ | $13.8\,\mu s$ → **13.7배** | $1.8\,\mu s$ → **3.4배** |
| R2a (하이브리드) | 652 KB | ${\sim}14.7$ | $17.3\,\mu s$ → **10.9배** | $1.8\,\mu s$ → **3.4배** |
| INT4 | 1.22 MB | ${\sim}3$ | $24\,\mu s$ → 7.8배 | $0.8\,\mu s$ → 7.6배 |

- CPU/엣지급($I^*$ 큼)에서는 압축률 우위가 그대로 속도 우위가 된다(10–16배). GPU FP32처럼 $I^*$ 가 낮은 곳에서는 연산 상한 $4I^*/(2{+}C_{eff})$ 에 먼저 걸려 3–5배로 제한된다 — **본 방식의 속도 최적 표적은 대역폭 대비 연산이 풍부한 하드웨어(CPU, NPU, 엣지)다.**
- 대배치는 따름정리 9.2 에 의해 패리티가 상한(불변).

### 17.5 요약: 목표에 대한 이론의 답

1. **정확도 최대 보존**: 장 위 타깃은 $10^{-4}$ (128b) ~ $3\times10^{-6}$ (160b) — 사실상 무손실급. 일반 LLM 층은 하이브리드로 INT4 동급($0.10\,\sigma$)이 하한 목표이며, 이는 $c \ge 0.5$ 실측을 전제로 10:1 이상에서 달성 가능하다.
2. **압축률 최대**: 정확도 제약 없는 장 부호화는 해상도 무계(1024:1+). 정확도 보존 제약 하에서는 $c$ 가 결정하며 이론 상한은 "INT4 정확도 @ $\approx 8/(1-c)^{...}$" 대신 위 표의 $c$-사다리를 따른다.
3. **속도 최대**: CPU급 $I^* = 40$ 에서 10–16배, 이론 천장 $4I^*/(2+C_g)$. 속도·압축·정확도 세 목표가 동시에 최적화되는 지점은 R2 하이브리드 + CPU/엣지 배포다.

모든 수치는 유도된 조건부 이론값이며, 자유 변수는 $c$ (원자 에너지 포획률) 하나로 압축되었다. $c$ 의 실측(16장 프로토콜 7)이 이 표를 확정한다.

## 부록 A. 위상-비트 미분 (3장)

### A.1 정리 3.1 의 완전한 귀납

주장: $\dfrac{d^n}{dt^n}\big[A\sin(\omega t + \varphi)\big] = A\omega^n \sin\big(\omega t + \varphi + n\tfrac{\pi}{2}\big)$.

$n = 0$ 은 자명. $n$ 에서 성립을 가정하면
$$\frac{d^{n+1}}{dt^{n+1}} f = \frac{d}{dt}\Big[A\omega^n \sin\big(\omega t + \varphi + n\tfrac{\pi}{2}\big)\Big] = A\omega^{n+1}\cos\big(\omega t + \varphi + n\tfrac{\pi}{2}\big)$$
이고 $\cos u = \sin(u + \pi/2)$ 에 의해 $= A\omega^{n+1}\sin\big(\omega t + \varphi + (n{+}1)\tfrac{\pi}{2}\big)$. $\square$

### A.2 명제 A.1 (원형 트랙의 유일성 — sin 은 선택이 아니라 강제다)

**명제**. $g: \mathbb{R} \to \mathbb{R}$ 가 유계(또는 다항 성장)이고 어떤 상수 $c \ne 0$ 에 대해 $g'(u) = g(u + c)$ 를 만족하면, $g(u) = A\sin(u + \varphi)$ 이고 $c \equiv \pi/2 \pmod{2\pi}$ 이다 (주파수는 변수 재척도로 일반화).

**증명**. $g$ 가 다항 성장이므로 완화 분포(tempered distribution)로서 푸리에 변환 $\hat g$ 를 갖는다. 방정식의 양변을 변환하면
$$i\xi\,\hat g(\xi) = e^{ic\xi}\,\hat g(\xi) \quad\Longrightarrow\quad \big(i\xi - e^{ic\xi}\big)\,\hat g = 0$$
따라서 $\operatorname{supp}\hat g \subset \{\xi : i\xi = e^{ic\xi}\}$. 실수 $\xi$ 에서 $|e^{ic\xi}| = 1$ 이므로 $|\xi| = 1$, 즉 $\xi = \pm 1$ 뿐이다. $\xi = 1$ 에서 조건은 $i = e^{ic}$, 즉 $c \equiv \pi/2 \pmod{2\pi}$ ($\xi = -1$ 도 같은 조건). 인자 $h(\xi) = i\xi - e^{ic\xi}$ 의 영점이 단순함을 확인한다: $c = \pi/2$, $e^{ic} = i$ 를 대입하면 $h'(1) = i - ic\,e^{ic} = i - i\cdot\tfrac{\pi}{2}\cdot i = i + \tfrac{\pi}{2} \ne 0$. 단순 영점이므로 $\hat g$ 는 $\delta_{\pm 1}$ 의 결합만 가능하고(델타의 도함수 성분은 방정식을 위반), 실함수 조건으로 $g(u) = A\sin(u + \varphi)$. $\square$

이로써 3장의 함수족 선택이 임의가 아님이 확정된다: **위상-이동 미분 성질을 갖는 유계 생성원은 사인뿐이다.**

### A.3 정리 3.2 의 정확성과 자유 스펙트럼의 오차 전파

위상 격자 $\varphi = 2\pi q/2^b$ 에서 $\pi/2 = 2\pi \cdot 2^{b-2}/2^b$ 는 격자점이므로 $D_{bit}: q \mapsto q + 2^{b-2}$ 는 양자화와 정확히 가환한다(본문). 일반화 미분(정리 13.2)의 $\delta = \mathrm{atan2}(\lambda, \rho)$ 는 격자점이 아닐 수 있고, 두 처리가 있다:

1. **자유 $\lambda$**: $q_\delta = \mathrm{round}(2^b\delta/2\pi)$ 를 저장하면 $n$계 미분의 위상 오차는 $|n\,(2\pi q_\delta/2^b - \delta)| \le n\pi/2^b$. $n q_\delta$ 를 한 번에 더하면 반올림은 1회다.
2. **$\delta$-격자 파라미터화 (정확성 복원)**: 스펙트럼을 $\lambda$ 대신 $\delta$ 로 매개화한다 — $\delta$ 를 격자점으로 제한하고 $\lambda = \rho\tan\delta$ 로 정의하면, 미분의 위상 이동이 구성상 정확해진다. 진폭 인자는 $\sqrt{\rho^2 + \lambda^2} = \rho\sec\delta$ 로 닫힌형이다.

### A.4 정리 3.4 의 상세 ($\tanh$ 불가능성)

$t(x) = \tanh x$, $t' = 1 - t^2$. 임의의 다항식 $P$ 에 대해
$$\frac{d}{dx}P(t(x)) = P'(t)\,(1 - t^2)$$
이므로 대수 $\mathbb{R}[t]$ 는 미분에 닫혀 있다. 차수를 보자: $\deg P = n \ge 1$, 최고차항 $a_n t^n$ 이면
$$P'(t)(1 - t^2) = \big(n a_n t^{n-1} + \cdots\big)(1 - t^2) = -n a_n t^{n+1} + (\text{저차항})$$
으로 최고차 계수 $-n a_n \ne 0$, 즉 **차수가 정확히 1 증가**한다. $\tanh = t$ 는 차수 1이므로 $k$계 도함수는 차수 $k+1$ 의 다항식이다. 서로 다른 차수의 다항식들은 선형 독립이므로 $\{\tanh^{(k)}\}_{k \ge 0}$ 는 무한 차원 공간을 생성한다. 유한 라벨 집합 $S$ 가 미분에 닫혀 있으면 $\operatorname{span}(S)$ 는 유한 차원이고 미분 불변이어야 하므로 $\tanh$ 를 포함할 수 없다. $\square$

**따름**: $\ln$ 도 동일 — $\ln^{(k)}(x) = (-1)^{k-1}(k-1)!\,x^{-k}$ ($k \ge 1$)는 서로 다른 동차 차수라 선형 독립 무한족이다.

## 부록 B. Busemann 좌표의 성질 (명제 13.1)

전 절에 걸쳐 $P(z,b) = \dfrac{1-|z|^2}{|z-b|^2}$, $B_b = \log P$, $\lambda_z = \dfrac{2}{1-|z|^2}$, $|b| = 1$.

### B.1 $B_b$ 는 Busemann 함수다

Busemann 함수의 정의는 $\beta_b(z) = \lim_{t\to\infty}\big[d(z, \gamma(t)) - t\big]$ ($\gamma$ 는 원점에서 $b$ 로 가는 단위속도 측지선)이다. $b = 1$ 로 두면 $\gamma(t) = \tanh(t/2)$ (2장의 $d_h(r) = 2\,\mathrm{artanh}\,r$ 를 역으로 쓴 것). 거리 공식
$$\cosh d(z, \gamma(t)) = 1 + \frac{2|z - \tanh(t/2)|^2}{(1-|z|^2)\,\mathrm{sech}^2(t/2)}$$
에서 $t \to \infty$ 일 때 $\mathrm{sech}^2(t/2) = 4e^{-t}(1 + o(1))$, $|z - \tanh(t/2)|^2 \to |z-1|^2$ 이므로
$$\cosh d(z,\gamma(t)) = \frac{|z-1|^2\,e^{t}}{2\,(1-|z|^2)}\,(1+o(1))$$
$\cosh d = \tfrac{1}{2}e^{d}(1+o(1))$ 와 비교하면
$$d(z, \gamma(t)) - t \;\longrightarrow\; \log\frac{|z-1|^2}{1-|z|^2} = -\log P(z, 1)$$
즉 $\beta_b = -\log P = -B_b$. $\square$ (부호: $B_b$ 는 $b$ 쪽으로 갈수록 증가.)

### B.2 단위 기울기: $\|\nabla B_b\|_{hyp} = 1$ (전 영역, 직접 대수)

$\nabla_{eucl} B = \nabla \log(1-|z|^2) - \nabla \log|z-b|^2 = \dfrac{-2z}{1-|z|^2} - \dfrac{2(z-b)}{|z-b|^2}$.

$|\nabla_{eucl}B|^2 = 4\left[\dfrac{|z|^2}{(1-|z|^2)^2} + \dfrac{2\langle z, z-b\rangle}{(1-|z|^2)|z-b|^2} + \dfrac{1}{|z-b|^2}\right]$ 이고, 이것이 $\lambda_z^2 = \dfrac{4}{(1-|z|^2)^2}$ 과 같음은 다음 항등식과 동치다:
$$2\langle z, z-b\rangle + (1 - |z|^2) = |z - b|^2$$
전개하면 좌변 $= 2|z|^2 - 2\langle z,b\rangle + 1 - |z|^2 = |z|^2 - 2\langle z,b\rangle + 1$, 우변 $= |z|^2 - 2\langle z,b\rangle + |b|^2 = |z|^2 - 2\langle z,b\rangle + 1$. 일치. 따라서 $|\nabla_{eucl}B| = \lambda_z$ 이고, 등각 계량에서 $\|\nabla B\|_{hyp} = |\nabla_{eucl}B|/\lambda_z = 1$. $\square$

### B.3 등위선은 $b$ 에 접하는 호로사이클

$P(z,b) = c$ ⟺ $c|z-b|^2 + |z|^2 = 1$. $b = 1$ 로 두고 전개하면
$$|z|^2 - \frac{2c}{c+1}x + \frac{c-1}{c+1} = 0$$
— 중심 $\big(\tfrac{c}{c+1}, 0\big)$, 반지름 $\tfrac{1}{c+1}$ 의 원이다. 중심 거리 + 반지름 $= \tfrac{c}{c+1} + \tfrac{1}{c+1} = 1$ 이므로 단위원에 $b = 1$ 에서 내접한다: 호로사이클. $\square$

### B.4 라플라시안: $\Delta_{eucl} B_b = -\lambda_z^2$

$\log|z-b|^2$ 은 $z \ne b$ 에서 조화함수이므로 기여가 없다. $u = 1 - |z|^2$ 로 두면 $\Delta u = -4$, $|\nabla u|^2 = 4|z|^2$ 이고
$$\Delta \log u = \frac{u\,\Delta u - |\nabla u|^2}{u^2} = \frac{-4(1-|z|^2) - 4|z|^2}{(1-|z|^2)^2} = \frac{-4}{(1-|z|^2)^2} = -\lambda_z^2 \qquad \square$$

### B.5 기울기 흐름은 측지선이다

축 위($z = r$, $b = 1$)에서 $\nabla B$ 는 B.2 계산에 의해 실축 방향이고, 실축 지름은 측지선이므로 성립한다. 일반점은 $b$ 를 고정하는 뫼비우스 변환(아래 C.3 의 공변성에 의해 $B_b$ 를 상수 덧셈까지 보존, 즉 기울기 선을 기울기 선으로 보냄)의 궤도가 원판 전체를 덮으므로 축의 경우로 환원된다. $\square$

## 부록 C. 고유함수, 미분 정리, 뫼비우스 공변성 (13장)

### C.1 $\Delta_{\mathbb{H}}\,e^{\mu B_b} = \mu(\mu - 1)\,e^{\mu B_b}$ — 그리고 $\rho = \tfrac{1}{2}$ 는 강제된다

2차원 등각 계량에서 $\Delta_{\mathbb{H}} = \lambda_z^{-2}\Delta_{eucl}$ 이다. 연쇄법칙으로
$$\Delta_{eucl}\,e^{\mu B} = e^{\mu B}\big(\mu\,\Delta_{eucl}B + \mu^2 |\nabla_{eucl}B|^2\big) = e^{\mu B}\big(-\mu\lambda_z^2 + \mu^2\lambda_z^2\big) = \mu(\mu-1)\,\lambda_z^2\,e^{\mu B}$$
(B.2 와 B.4 를 대입). 따라서
$$\Delta_{\mathbb{H}}\,e^{\mu B_b} = \mu(\mu - 1)\,e^{\mu B_b}$$
$\mu = \rho + i\lambda$ 로 놓으면 고유값은 $\mu^2 - \mu = (\rho^2 - \lambda^2 - \rho) + i\lambda(2\rho - 1)$. **고유값이 실수일 필요충분조건은 ($\lambda \ne 0$ 에서) $\rho = \tfrac{1}{2}$** 이며, 그때 고유값 $= -(\lambda^2 + \tfrac{1}{4})$. 즉 본문의 $\rho = \tfrac12$ 는 관례가 아니라 자기수반 스펙트럼의 실수성이 강제하는 값이고, $-\tfrac14$ 는 $\mathbb{H}^2$ 의 스펙트럼 갭이다. $\square$

### C.2 정리 13.2 의 상세

보조정리 (코사인 합성): $a\cos u - c\sin u = \sqrt{a^2+c^2}\,\cos(u + \mathrm{atan2}(c, a))$. — 우변을 전개하면 $\sqrt{a^2+c^2}(\cos u\cos\delta - \sin u\sin\delta)$ 이고 $\cos\delta = a/\sqrt{a^2+c^2}$, $\sin\delta = c/\sqrt{a^2+c^2}$ 를 대입하면 좌변. $\square$

B.5 에 의해 $b$-측지선은 $B$ 의 기울기 흐름이고 B.2 에 의해 그 흐름은 단위속도이므로, 흐름 매개변수 $t$ 에 대해 $dB/dt = \|\nabla B\|^2_{hyp} = 1$. 따라서 $W = A e^{\rho B}\cos(\lambda B + \varphi)$ 의 흐름 미분은 $B$-미분과 같고
$$\partial_t W = A e^{\rho B}\big[\rho\cos(\lambda B + \varphi) - \lambda\sin(\lambda B + \varphi)\big] = A\sqrt{\rho^2+\lambda^2}\;e^{\rho B}\cos\big(\lambda B + \varphi + \mathrm{atan2}(\lambda,\rho)\big)$$
보조정리를 $a = \rho$, $c = \lambda$ 로 적용했다. $n$계는 귀납으로 진폭 $(\rho^2+\lambda^2)^{n/2}$, 위상 $+n\delta$. $\square$

### C.3 뫼비우스 공변성: $P(gz, gb) = P(z,b)\,/\,|g'(b)|$

$g(z) = e^{i\alpha}\dfrac{z - a}{1 - \bar a z}$ ($|a| < 1$) 에 대해 두 Blaschke 항등식이 성립한다 (직접 전개로 검증 가능):
$$1 - |g(z)|^2 = \frac{(1-|a|^2)(1-|z|^2)}{|1 - \bar a z|^2},
\qquad
|g(z) - g(w)|^2 = \frac{(1-|a|^2)^2\,|z-w|^2}{|1-\bar a z|^2\,|1-\bar a w|^2}$$
$w = b$ ($|b|=1$)로 두고 비를 취하면
$$P(gz, gb) = \frac{1-|g z|^2}{|g z - g b|^2} = P(z, b)\cdot\frac{|1 - \bar a b|^2}{1 - |a|^2}$$
한편 $g'(z) = e^{i\alpha}\dfrac{1-|a|^2}{(1-\bar a z)^2}$ 이므로 $|g'(b)| = \dfrac{1-|a|^2}{|1-\bar a b|^2}$, 즉
$$P(gz, gb) = \frac{P(z,b)}{|g'(b)|} \quad\Longrightarrow\quad B_{gb}(gz) = B_b(z) - \log|g'(b)| \qquad \square$$

따름 (15.7절의 게이지, 13.2절의 lo 해석): 평면파의 뫼비우스 당김은
$$e^{(\rho+i\lambda)B_b(g^{-1}z)} = e^{(\rho+i\lambda)B_{g b}(z)}\cdot e^{-(\rho+i\lambda)\log|g'(b)|}$$
— 다시 평면파이며, 파라미터 변화는 $b \mapsto g(b)$ (경계점 이동), $\log A \mapsto \log A - \rho\log|g'(b)|$, $\varphi \mapsto \varphi - \lambda\log|g'(b)|$ 로 닫힌다. 원자족은 뫼비우스 군의 정확한 표현 공간이다.

### C.4 15.4 분리 항등식의 검증

$\cos(a - b + \varphi) = \cos\big((a+\varphi) - b\big) = \cos(a+\varphi)\cos b + \sin(a+\varphi)\sin b$ — 코사인 차 공식 그대로. 봉투 인자도 $e^{\rho(B(z)-B(w))} = e^{\rho B(z)}\cdot e^{-\rho B(w)}$ 로 분리된다. $\square$

## 부록 D. 정보이론 (8장, 12장)

### D.1 정리 8.1 (Shannon 하한에 의한 역정리)

분산 $\sigma^2$ 인 i.i.d. 소스 $X$, 재현 $\hat X$, 왜곡 $D = \mathbb{E}(X-\hat X)^2$. 레이트는
$$R \ge I(X; \hat X) = h(X) - h(X \mid \hat X) \ge h(X) - h(X - \hat X)$$
(조건 제거는 엔트로피를 늘리고, $h(X-\hat X \mid \hat X) \le h(X-\hat X)$). 분산 $\le D$ 인 확률변수 중 미분 엔트로피 최대는 가우시안이므로 $h(X - \hat X) \le \tfrac{1}{2}\log(2\pi e D)$. $X$ 가 가우시안이면 $h(X) = \tfrac{1}{2}\log(2\pi e\sigma^2)$ 이고
$$R \ge \frac{1}{2}\log\frac{\sigma^2}{D} \quad\Longleftrightarrow\quad D \ge \sigma^2\,2^{-2R} \qquad \square$$
$B = 64$, 128비트: $R = 2^{-5}$ bpw → $D \ge \sigma^2 2^{-1/16} = 0.958\sigma^2$.

### D.2 명제 12.2 의 오차 상계

$f$ 가 $s$-Hölder ($|f(x)-f(y)| \le L\|x-y\|^s$, $0 < s \le 1$)이면 셀 $Q_{ij}$ (지름 $\sqrt 2/B$) 중점 규칙에서
$$\Big|\int_{Q_{ij}} f - \frac{f(x_{ij})}{B^2}\Big| \le \frac{1}{B^2}\sup_{x \in Q_{ij}}|f(x) - f(x_{ij})| \le \frac{L}{B^2}\Big(\frac{\sqrt 2}{B}\Big)^{s}$$
셀 $B^2$ 개를 합하면 총 오차 $\le L(\sqrt2/B)^s = O(B^{-s})$. 고계 매끄러움($s > 1$)은 표준 복합 구적 이론으로 동일 형태. $\square$

### D.3 비가우시안 소스의 Lloyd-Max 왜곡: 첨도 1차 보정

17.3절의 운용점 예측은 잔차가 가우시안이라는 가정 위에 있다. 실측 층에서 잔차(또는 $c \approx 0$ 이면 가중치 자체)의 꼬리가 가우시안보다 두꺼우면 가우시안 설계 양자화기의 실제 왜곡은 이론값을 넘는다. 본 절은 그 초과분을 측정 가능한 모멘트(초과첨도)로 닫힌형 보정한다.

**설정.** 평균 0, 분산 1 인 소스 밀도 $p$, 가우시안 최적 Lloyd-Max 양자화기(레벨 $l_i$, 셀 $C_i = [t_{i-1}, t_i)$)는 고정한다. 왜곡은
$$D[p] = \sum_i \int_{C_i} (x - l_i)^2\, p(x)\, dx$$
로 $p$ 에 **선형**이다.

**전개.** 왜도 $\gamma$(3차 큐뮬런트), 초과첨도 $\kappa$(4차 큐뮬런트)인 표준화 밀도의 Gram-Charlier A-급수는
$$p(x) = \varphi(x)\Big[1 + \frac{\gamma}{6}\mathrm{He}_3(x) + \frac{\kappa}{24}\mathrm{He}_4(x) + \cdots\Big],\qquad \mathrm{He}_3 = x^3 - 3x,\ \ \mathrm{He}_4 = x^4 - 6x^2 + 3.$$
$D$ 의 선형성으로
$$D[p] = D_\varphi + \frac{\gamma}{6}\Delta_3 + \frac{\kappa}{24}\Delta_4 + \cdots,\qquad \Delta_m = \sum_i \int_{C_i} (x-l_i)^2\,\mathrm{He}_m(x)\,\varphi(x)\,dx.$$

**왜도 항의 소거.** Lloyd-Max 양자화기는 원점 대칭($l_{-i} = -l_i$, $t_{-i} = -t_i$)이다. 셀 $C_i$ 와 그 거울 셀의 기여를 짝지어 $x \to -x$ 치환하면 $(x - l_i)^2 \to (x - l_i)^2$, $\mathrm{He}_3(-x) = -\mathrm{He}_3(x)$, $\varphi$ 는 우함수이므로 두 기여가 정확히 상쇄된다: $\Delta_3 = 0$. 따라서 최초 보정은 4차 항이다:
$$\boxed{\,D(\kappa) = D_\varphi + \kappa\, D',\qquad D' = \frac{\Delta_4}{24}\,}$$

**닫힌형 평가.** $(x - l)^2 \mathrm{He}_4(x) = x^6 - 2l x^5 + (l^2 - 6)x^4 + 12l x^3 + (3 - 6l^2)x^2 - 6l x + 3l^2$ 이고, 절단 모멘트 $I_m(a,b) = \int_a^b x^m \varphi(x)\,dx$ 는 부분적분 점화식
$$I_0 = \Phi(b) - \Phi(a),\quad I_1 = \varphi(a) - \varphi(b),\quad I_m = (m-1)\,I_{m-2} + a^{m-1}\varphi(a) - b^{m-1}\varphi(b)$$
로 셀별 닫힌형이다 (무한 경계에서는 $a^{m-1}\varphi(a) \to 0$). 2비트 가우시안 Lloyd-Max 에서 수치 평가하면 $D_\varphi = 0.117482$, $D' = 0.031689$.

**유효 범위.** 1차 절단이므로 상위 항을 무시한다: 적용 조건은 $|\kappa| \ll 1$ 이며, 절단 오차는 $\mathrm{He}_6$ 항 (계수 $(\kappa_6 + 10\kappa_3^2)/720$) 과 $\mathrm{He}_8$ 항 (계수 $(\kappa_8 + 35\kappa_4^2)/8!$) 에서 나오므로 $O(\kappa_6) + O(\kappa^2)$ 이다. 검증용 합성 소스로는 분산 혼합 $X = \sigma_S Z$, $\sigma_S^2 \in \{1+\delta, 1-\delta\}$ 등확률을 쓴다 — 이 소스는 $\kappa = 3\delta^2$ 이고 6차 큐뮬런트가 정확히 0 이라($m_6 = 15(1+3\delta^2)$, $\kappa_6 = m_6 - 15 m_4 + 30 = 0$) $\mathrm{He}_6$ 항이 소거되고, 잔여 오차는 $\mathbb{E}[\mathrm{He}_8] = 105\delta^4$ 의 $O(\kappa^2)$ 항뿐이라 1차 보정의 정밀 검증에 적합하다.

**17.3절 예측식의 보정.** 잔차 백색화 후 상대 RMSE 예측은
$$\text{RMSE}_{rel} = \sqrt{D(\kappa)\,(1 - c)},\qquad \kappa = \text{잔차의 실측 초과첨도}$$
이며 $\kappa = 0$ 에서 기존 식으로 환원된다. 실증 (kogpt2 층0 c_fc, $\kappa = 0.0838$): 예측 왜곡비 $D(\kappa)/D_\varphi = 1.0226$ vs 실측 1.0214, RMSE 비 1.0112 vs 실측 1.0107 — 잔차 0.05%는 $n = 2.36{\times}10^6$ 의 신뢰 밴드 내다.

## 부록 E. 수치 해석 (6장, 7장)

### E.1 Sterbenz 보조정리의 증명

이진 부동소수점 $a, b > 0$ 이 $\tfrac{b}{2} \le a \le 2b$ 이면 $a - b$ 는 정확히 표현된다. 일반성을 잃지 않고 $a \ge b$ (반대면 부호 교환): $b = m_b 2^{e_b}$, $a = m_a 2^{e_a}$, $m < 2^p$ (정수 가수), $e_a \ge e_b$. 그러면
$$a - b = \big(m_a 2^{e_a - e_b} - m_b\big)\,2^{e_b} =: M\,2^{e_b}, \qquad M \in \mathbb{Z}_{\ge 0}$$
$a \le 2b$ 이므로 $a - b \le b$, 즉 $M \le m_b < 2^p$. 따라서 $M$ 은 $p$ 비트 가수에 들어가고 $a - b = M2^{e_b}$ 는 표현 가능. $\square$

$r \in [\tfrac12, 1]$, $a = 1$, $b = r$ 은 조건 $r/2 \le 1 \le 2r$ 을 만족하므로 $\mathrm{fl}(1-r) = 1-r$ 정확.

### E.2 $(1-r)(1+r)$ 의 오차 상계

$\mathrm{fl}(1+r) = (1+r)(1+\varepsilon_1)$, $|\varepsilon_1| \le u$; 곱셈 반올림 $(1+\varepsilon_2)$, $|\varepsilon_2| \le u$. E.1 에 의해 $1-r$ 항은 무오차이므로
$$\mathrm{fl}\big((1-r)(1+r)\big) = (1-r^2)(1+\varepsilon_1)(1+\varepsilon_2) = (1-r^2)\big(1 + \varepsilon\big), \quad |\varepsilon| \le 2u + u^2$$
$r$ 에 무관한 균일 상계다. 대조: $\mathrm{fl}(1 - \mathrm{fl}(r^2))$ 은 $r^2$ 의 절대 반올림 오차($\approx u/2$, $r \approx 1$)가 $1 - r^2$ 에 상대화되어 $\dfrac{u/2}{1-r^2}$ — $r = 1 - 2^{-12}$ 에서 약 $12\%$. $\square$

### E.3 사분파 LUT 보간 오차 (6.1절 상계의 유도)

선형 보간의 표준 오차식: 구간 $[x_0, x_1]$, $h = x_1 - x_0$ 에서 $f(x) - p(x) = \tfrac{1}{2}f''(\xi)(x-x_0)(x-x_1)$ 이고 $\max_x |(x-x_0)(x-x_1)| = h^2/4$ 이므로
$$\max|f - p| \le \frac{h^2}{8}\max|f''|$$
$f = \sin$, $|f''| \le 1$, $h = \tfrac{\pi/2}{2^k}$: 상계 $\dfrac{1}{8}\big(\tfrac{\pi}{2^{k+1}}\big)^2$. $k = 12$ → $1.84 \times 10^{-8}$. $\square$

## 부록 F. 기하 잡정리

### F.1 아핀 군의 불변 계량은 쌍곡 계량이다 (13.1절)

아핀 군 원소를 $(b, a)$, $a > 0$ (작용 $x \mapsto ax + b$)로 좌표화하면 군 곱은 $(b_0, a_0)\cdot(b, a) = (a_0 b + b_0,\; a_0 a)$ 이다. 좌이동 $L_{(b_0,a_0)}$ 의 미분은 $(db, da) \mapsto (a_0\,db, a_0\,da)$ 이므로, 후보 계량 $ds^2 = (db^2 + da^2)/a^2$ 의 당김은
$$\frac{a_0^2(db^2 + da^2)}{(a_0 a)^2} = \frac{db^2 + da^2}{a^2}$$
— 좌불변. 이는 상반평면의 곡률 $-1$ 쌍곡 계량이다(표준 계산). 따라서 위치-스케일 공간은 $\mathbb{H}^2$ 와 등거리 동형이고, 케일리 변환으로 푸앵카레 원판과 동형이다. $\square$

### F.2 리만 그래디언트의 극좌표 공식 (2장)

계량 행렬 $G = \mathrm{diag}(g_{rr}, g_{\theta\theta})$ 에서 $\mathrm{grad} f = G^{-1}\nabla f$ 이므로 성분별로
$$(\mathrm{grad} f)_r = \frac{\partial_r f}{g_{rr}} = \frac{(1-r^2)^2}{4}\partial_r f, \qquad
(\mathrm{grad} f)_\theta = \frac{\partial_\theta f}{g_{\theta\theta}} = \frac{(1-r^2)^2}{4r^2}\partial_\theta f \qquad \square$$

### F.3 $B_b$ 와 $d_h$ 의 일치 (명제 13.1-1)

$b = 1$, $z = r \in [0,1)$: $|z - b|^2 = (1-r)^2$ 이므로
$$B_b(r) = \log\frac{1-r^2}{(1-r)^2} = \log\frac{1+r}{1-r} = 2\,\mathrm{artanh}(r) = d_h(r) \qquad \square$$
