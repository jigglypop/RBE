# RBE Linear Layer 수학적 설계 및 구현

## 1. 문제 정의 및 목표

### 1.1 기본 문제
신경망의 Linear 레이어는 다음과 같이 정의됩니다:

```
Y = XW + b
```

여기서:
- X ∈ ℝ^(B×D_in): 입력 텐서 (배치 크기 B, 입력 차원 D_in)
- W ∈ ℝ^(D_in×D_out): 가중치 행렬 (압축 대상)
- b ∈ ℝ^(D_out): 편향 벡터
- Y ∈ ℝ^(B×D_out): 출력 텐서

### 1.2 압축 목표
- **압축률**: 150:1 이상
- **정확도**: RMSE < 0.001
- **속도**: 원본 대비 동등하거나 향상된 추론 속도

## 2. 수학적 사영 이론

### 2.1 블록 분해 기법

가중치 행렬 W를 k×l 개의 블록으로 분할:

```
W = [W₁₁  W₁₂  ...  W₁ₗ]
    [W₂₁  W₂₂  ...  W₂ₗ]
    [  ⋮    ⋮   ⋱    ⋮ ]
    [Wₖ₁  Wₖ₂  ...  Wₖₗ]
```

각 블록 Wᵢⱼ ∈ ℝ^(bₕ×bᵥ)는 하나의 Packed256 시드로 압축됩니다.

### 2.2 최적 블록 크기 결정

**이론적 분석:**

압축률과 정확도의 트레이드오프를 고려한 최적 블록 크기:

```
bₒₚₜ = argmin_{b} [λ₁ · RMSE(b) + λ₂ · CR⁻¹(b)]
```

여기서:
- RMSE(b): 블록 크기 b에서의 평균 재구성 오차
- CR(b): 블록 크기 b에서의 압축률
- λ₁, λ₂: 가중치 파라미터

**경험적 공식:**

```
bₒₚₜ = ⌊√(D_in × D_out / target_CR)⌋
```

### 2.3 RBE 사영 함수

각 블록 Wᵢⱼ에 대해, RBE 기저 함수로의 사영:

```
Wᵢⱼ(r,θ) ≈ Σₘ cₘ · φₘ(r,θ)
```

여기서:
- φₘ(r,θ): m번째 RBE 기저 함수
- cₘ: 사영 계수 (Packed256에 인코딩)
- (r,θ): 푸앵카레 볼 좌표 (정규화된 블록 인덱스)

## 3. 압축 알고리즘

### 3.1 좌표 정규화

블록 내 위치 (i,j)를 푸앵카레 볼 좌표로 변환:

```
r = √[(2i/bₕ - 1)² + (2j/bᵥ - 1)²] / √2
θ = arctan2(2j/bᵥ - 1, 2i/bₕ - 1)
```

정규화 조건: r ∈ [0,1), θ ∈ [0,2π)

### 3.2 최적화 목적 함수

각 블록에 대한 RBE 파라미터 최적화:

```
minimize: Σᵢⱼ [Wᵢⱼ - f_RBE(rᵢⱼ, θᵢⱼ; 𝒫)]²
```

여기서:
- f_RBE: RBE 기저 함수
- 𝒫: Packed256 파라미터 세트
- (rᵢⱼ, θᵢⱼ): 정규화된 좌표

### 3.3 적응적 기저 선택

블록의 특성에 따른 최적 기저 함수 선택:

```
basis_id* = argmin_{k} RMSE_k(W_block)
```

기저 함수별 특성:
- **basis_id=0**: 일반적인 삼각함수 조합
- **basis_id=1**: 고주파 패턴 (어텐션 가중치)
- **basis_id=2**: 저주파 smooth 패턴 (FFN 가중치)
- **basis_id=3**: 쌍곡함수 (정규화 레이어)

## 4. 순전파 최적화

### 4.1 직접 계산 방식

기존 방식:
```
Y = X × W_restored = X × Σᵢⱼ restore(Sᵢⱼ)
```

최적화된 방식:
```
Y = Σᵢⱼ (X[:,block_row_i] × RBE_forward(Sᵢⱼ))
```

### 4.2 블록별 병렬 계산

```
Y[:, block_col_j] = Σᵢ (X[:, block_row_i] ⊗ f_RBE(Sᵢⱼ))
```

여기서 ⊗는 텐서 곱셈을 나타냅니다.

### 4.3 메모리 효율성

**스트리밍 방식**:
- 한 번에 하나의 블록만 메모리에 로드
- 출력 누적을 통한 점진적 계산
- O(max(B×bₕ, B×bᵥ)) 메모리 사용량

## 5. 수치 안정성

### 5.1 그라디언트 클리핑

역전파 시 그라디언트 폭발 방지:

```
∇W_clip = clip(∇W, -τ, τ)
```

권장값: τ = 1.0

### 5.2 정규화 기법

**가중치 정규화**:
```
L_reg = λ_reg · Σᵢⱼ ||Sᵢⱼ||₂²
```

**스펙트럼 정규화**:
```
W_normalized = W / σ_max(W)
```

여기서 σ_max는 최대 특이값입니다.

## 6. 성능 분석

### 6.1 계산 복잡도

**압축 시간**: O(k×l×T_opt)
- k×l: 블록 수
- T_opt: 블록당 최적화 시간

**추론 시간**: O(B×D_in×D_out/k×l)
- 블록 병렬 처리로 인한 속도 향상

**메모리 사용량**: 
- 압축: O(k×l×256) bits = O(k×l×32) bytes
- 원본: O(D_in×D_out×32) bits = O(D_in×D_out×4) bytes
- 압축률: (D_in×D_out×4) / (k×l×32) = D_in×D_out / (8×k×l)

### 6.2 정확도 보장

**이론적 오차 한계**:
```
||W - W_RBE||_F ≤ ε × ||W||_F
```

여기서 ε는 목표 상대 오차입니다.

**실용적 기준**:
- RMSE < 0.001 (절대 오차)
- 상대 오차 < 0.1% (가중치 크기 대비)

## 7. 구현 전략

### 7.1 점진적 적용

1. **1단계**: 가장 큰 Linear 레이어부터 적용
2. **2단계**: 압축률과 정확도 검증
3. **3단계**: 전체 모델로 확장

### 7.2 하이브리드 접근

- **큰 레이어**: RBE 압축 적용
- **작은 레이어**: 원본 유지
- **임계값**: 1M 파라미터 이상

### 7.3 동적 최적화

런타임에서 블록 크기와 기저 함수를 동적으로 조정:

```
if RMSE > threshold:
    decrease_block_size()
    or switch_basis_function()
```

## 9. 수학적 검증

### 9.1 수렴성 증명

RBE 최적화의 수렴성:

**정리**: 목적 함수 f(𝒫) = ||W - f_RBE(𝒫)||²_F는 적절한 학습률 하에서 지역 최솟값으로 수렴합니다.

**증명 스케치**:
1. f(𝒫)는 연속이고 하방 유계
2. ∇f(𝒫)는 Lipschitz 연속
3. Adam 옵티마이저의 수렴성 보장

### 9.2 근사 오차 분석

**정리**: k개의 RBE 기저 함수를 사용한 근사의 오차는 O(k⁻¹/²)로 감소합니다.

이는 RBE 기저 함수의 완전성(completeness)에서 유도됩니다.
