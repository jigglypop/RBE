- 테스트: `layer_codec_test.rs` 에 합성 게이트 2종 (다양체 왕복 바닥일치, 잔차 부기 정합성), `hybrid_codec_test.rs` 에 L4 실층 테스트 1종 (#[ignore], 모델 존재 시 명시 실행).

## 3. c 실측과 실패 분석

### 3.1 c 실측 (좌표 학습 이전 하한)

| J | 64 | 128 | 256 | 512 |
|---|---|---|---|---|
| c | 0.000587 | 0.000752 | 0.000923 | 0.001103 |

- sigma = 2.2617e-2. 원자부 압축률 271.1:1 (15.5절 공식과 일치. 부호 34 KB).
- 고정 나선 좌표에서 c ~= 0.11% — 묶인 랭크 2J = 1024 가 자유 랭크 768 을 초과함에도 에너지 포획이 극소다. 커널 값이 좌표에 종속되는 묶인 인수분해에서 **좌표가 임의 고정이면 표현력이 사실상 소진됨**을 실측으로 보여준다 (15.5절 "핵심 대결"의 실증). 결론: 좌표 학습(리만 SGD)이 다음 병목이며, c 는 그 이후 재측정해야 한다.

### 3.2 L4-4 실패와 해소 (프로토콜 12 경로: 유도 보강 후 통과)

1차 실행에서 실측 RMSE 7.8295e-3 vs 가우시안 예측 7.7479e-3 (비 1.0105) 로 밴드(0.0023) 상단 위반.
조사: 독립 Python 재현에서 실층 경험 왜곡 D_emp/D_gauss = 1.0214 (RMSE 비 1.0107) — Rust 실측과 일치, 구현 버그 아님. 원인은 c ~= 0 에서 잔차 == W 자체이고 W 의 초과첨도 +0.0838 이 가우시안 가정을 위반.

해소 (사용자 승인: "실패는 업그레이드해서 통과"): 밴드 완화가 아니라 **이론 유도를 보강**했다.
- 논문 부록 D.3 신설: Gram-Charlier 4차 전개로 D(kappa) = D_phi + kappa D' 닫힌형 유도. 대칭 양자화기에서 왜도 항 Delta_3 = 0 소거 증명, 절단 모멘트 점화식, 유효범위(절단 오차 O(kappa_6) + O(kappa^2)) 명시.
- 구현: LloydMaxQuantizer::distortion_rel_kurtosis (hybrid_codec.rs) — 2비트에서 D_phi = 0.117482, D' = 0.031689.
- L3 가드 신설 (양자화기_첨도보정_이론일치_양측): 6차 큐뮬런트가 정확히 0 인 분산 혼합 소스 (kappa = 3 delta^2) 로 보정식을 몬테카를로 400만 표본 양측 판정 — 통과.
- paper-checker 에이전트 정합 판정 (계수·점화식·수치 손검산 일치). 지적 1건(절단 오차 서술에 He_8 의 O(kappa^2) 항 누락)은 논문에 정정 반영.
- 재실행: 실측/보정예측 비 = **0.9994** (kappa 실측 0.0831), 밴드 1 ± 0.0023 — **통과**.

### 3.3 전모델 순전파 대조 (진짜 GPT 테스트)

12층 전 matmul 가중치 48개 (c_attn, attn.c_proj, c_fc, mlp.c_proj) 를 각각 매칭 퍼슈트 J=512 + 잔차 2비트로 압축하고, 실제 한국어 문장(14토큰, 실토크나이저)을 candle 그래프로 순전파해 기준(원본 f32)과 대조했다. 총 692.75s.

- 게이트: 행렬별 f64 전파 상계 ||X dW||_F <= ||X||_F ||dW||_F — **48/48 통과**.
- 층별 c: 0.00037 ~ 0.00169 (평균 0.00079). 전 층에서 일관되게 극소 — 단층 결론(고정 좌표의 표현력 소진)이 모델 전체에서 재현됨. 행렬별 상대 RMSE 0.34 ~ 0.43 (2bpw 잔차 양자화가 지배).
- 종단 (비게이트 보고): 로짓 RMSE 2.85 (로짓 RMS 4.09 대비 상대 0.698), **다음 토큰 top-1 일치 1/14**.

해석: 파이프라인은 유도 상계 내에서 기계적으로 정확하나, 현 운용점(고정 나선 좌표 c ~= 0 + 2bpw)은 모델 예측을 보존하지 못한다. 행렬별 상대 오차 약 0.35 가 12층을 거치며 누적된 결과로, 좌표 학습(c 상승) 없이는 R2a 운용점이 성립하지 않음을 종단에서 정량 확인했다. 이는 17.3절 이론이 예측하는 바와 정합적이다 (c = 0 이면 잔차 비트가 전부이고 0.343 sigma 오차 = INT4 의 3.5배 나쁨).

## 4. 이론 대비 관찰

- 다양체 왕복 게이트는 양자화 바닥에 여유 있게 통과 — 코덱 자체 정합성은 문제없음.
- candle 대조는 Higham 상계 내 통과. 압축 순전파 오차 전파 상계(ratio 0.018)는 Cauchy-Schwarz 가 랜덤 입력에 느슨한 것으로 예상과 일치.
- 상대 출력 오차 0.357 은 상대 가중치 오차 0.346 (c ~= 0 에서 2bpw 잔차 양자화가 지배) 과 정합 — R2a 운용점은 c 가 커야 의미가 있음을 재확인.

## 4.5 돌파구: 좌표 학습 (리만 SGD, 15.6절 (a)) — 구현·실측 완료

전모델 실측(3.3절)이 확정한 병목(고정 좌표)을 해소하기 위해 좌표 학습을 구현했다.

### 진단 (프로토콜 7 저랭크 대결)

동일 비트 예산(64(M+N+J)비트 = f16 자유 랭크 약 4~5)의 SVD 상한 c 실측:

| 행렬 | 저랭크 상한 c(r_eq) | 고정 나선 실측 c | 갭 |
|---|---|---|---|
| h.0.mlp.c_fc | 0.094 | 0.0011 | 85배 |
| h.0.attn.c_attn | 0.153 | 0.0004 | 380배 |
| wpe (위치 임베딩) | 0.902 (r=16: 0.991) | 0.0121 | 75배 |
| wte (토큰 임베딩, 8192행 표본) | 0.243 | 미측정 | - |

트랜스포머 행렬은 백색이 아니며(상한 0.05~0.15), wpe 는 진짜 장(field)이다 (12.4절 적용 조건의 실증). 문제는 코덱이 아니라 좌표였다.

### 구현 (layer_codec.rs)

- 초기화: 상위 2 특이벡터(멱반복, 결정론) 를 원판에 사상 — 지배 구조를 Busemann 특징에 노출.
- 좌표 그래디언트: dK/dB 는 정리 13.2 위상 이동, dB/dz 는 부록 B.2 닫힌형. 리만 갱신 (1-|z|^2)^2/4 (5.4절 경계 감쇠) + r <= 0.9 재투영. 미니배치 SGD (고정 시드).
- 교대 최적화: 퍼슈트 -> 좌표 SGD -> 재적합, keep-best (라운드 0 = SVD 초기 퍼슈트보다 나빠질 수 없음 — 합성 테스트로 불변식 검증).
- 합성 검증 (좌표학습_기준선보존_개선_보고): 나선 0.214 -> SVD 초기 0.512 -> 교대 학습 0.714.

### 실층 결과 (rounds=6, sgd_steps=300, batch=96, J=512)

| 행렬 | 나선 c | 좌표학습 c | 개선 | 상한 대비 | 시간 |
|---|---|---|---|---|---|
| wpe (1024x768) | 0.0121 | **0.4352** | 36.0배 | 상한 0.902 의 48% | 74s |
| c_fc (768x3072) | 0.0011 | **0.0451** | 40.9배 | 상한 0.094 의 48% | 185s |

판정: 좌표 학습이 병목이었다는 진단이 정확했고, 두 행렬 모두 동일비트 저랭크 상한의 약 절반까지 도달했다 (경량 설정 기준 — 라운드·스텝·학습률 스케줄 미조정). 17.2절 손익분기(c > 0.105) 기준으로 wpe 는 원자 부호화가 크게 이득, c_fc 는 아직 미달 — c 사다리(층 유형별 적응 배분)가 다음 단계다.
