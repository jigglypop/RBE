# 정밀 검증 하네스 정의 (위상-비트 미분 · 평면 장 부호화 구현용)

문서 버전: 2 (체크포인트 계획·보고 양식·구현 명세·상수표·실패 대응 프로토콜 추가)

본 문서는 PAPER_POINCARE_RBE.md (재유도판, 부록 A-F 포함)의 구현이 이론 정밀도를 유지함을 보장하는 테스트 하네스의 규범 정의이자 **구현 체크포인트 계획서**다. 목적은 두 가지다: (1) 구현 오차가 이론 상계를 넘는 순간 테스트가 실패한다, (2) 허용오차를 실측에 맞춰 끼워넣는 일이 구조적으로 불가능하다 (CLAUDE.md 절대 규칙 2의 기계적 강제).

## 0. 세 가지 불변 원칙

1. **허용오차 리터럴 금지**: 테스트 코드의 assert 비교에 부동소수점 리터럴 허용오차를 직접 쓰지 않는다. 모든 허용오차는 `bounds` 모듈의 닫힌형 계산 함수에서 나오며, 각 함수는 논문 부록의 유도 번호를 주석으로 참조한다. 허용오차를 바꾸려면 유도를 바꿔야 하고, 유도 변경은 논문 수정 + 사용자 승인을 거친다.
2. **오라클 분리**: 참조 구현(`oracle`)은 최적화 없이 f64로 정의를 직역한 코드만 둔다. 오라클은 절대 프로덕션 경로를 호출하지 않는다 (자기 참조 검증 금지).
3. **결정론**: 모든 무작위 테스트는 고정 시드(`StdRng::seed_from_u64`)를 쓰고 시드를 테스트 함수에 명기한다. `from_entropy` 는 테스트에서 금지. 통계 판정의 신뢰계수는 5-시그마(오탐률 약 3e-7)로 고정하고 본 문서가 그 근거 문서다.

공용 검증 기반은 `src/core/math/verification.rs` 에 `#[cfg(test)]` 로 둔다 (Cargo.toml 변경 불필요):

```rust
#[cfg(test)]
pub mod verification {
    pub mod oracle {  // f64 직역 참조 구현. 최적화 금지.
        pub fn sin(x: f64) -> f64;                      // libm 그대로
        pub fn busemann(z: (f64, f64), theta_b: f64) -> f64;  // log((1-|z|^2)/|z-b|^2) 직역
        pub fn atom(z: (f64, f64), p: &AtomParams) -> f64;    // A e^{rho B} cos(lambda B + phi) 직역
        pub fn central_diff(f: impl Fn(f64) -> f64, x: f64, h: f64) -> f64;
    }
    pub mod bounds {  // 닫힌형 허용오차 계산기. 논문 부록 번호를 주석으로 명기.
        pub const U32: f64 = 5.960_464_477_539_063e-8;  // 2^-24, f32 단위 반올림
        pub const U64: f64 = 1.110_223_024_625_157e-16; // 2^-53

        pub fn lut_interp(k: u32) -> f64 { (PI / 2f64.powi(k as i32 + 1)).powi(2) / 8.0 }        // 부록 E.3
        pub fn sterbenz_product() -> f64 { 2.0 * U32 + U32 * U32 }                                // 부록 E.2
        pub fn phase_quant(b: u32) -> f64 { PI / 2f64.powi(b as i32) }                            // 7.3절 (반스텝)
        pub fn amp_quant(frac_bits: u32) -> f64 { LN_2 / 2f64.powi(frac_bits as i32 + 1) }        // 7.3절
        pub fn atom_eval(p: &AtomParams, r_max: f64) -> f64;  // 7.3절 합성 상계 (위상+진폭+LUT+r 항)
        pub fn dot_product(n: usize) -> f64 {                                                     // Higham 3.5
            let g = n as f64 * U32; g / (1.0 - g)   // gamma_n. 주의: Sum|x_i y_i| 에 상대적
        }
        pub fn central_diff(h: f64, m0: f64, m3: f64) -> f64 { h*h*m3/6.0 + 2.0*U64*m0/h }        // 표준 절단+반올림
        pub fn central_diff_h_opt(m0: f64, m3: f64) -> f64 { (3.0*U64*m0/m3).cbrt() }
        pub fn rmse_ci_rel(n: usize) -> f64 { 5.0 / (2.0 * n as f64).sqrt() }                     // 카이제곱 CLT, 5-시그마
        pub fn shannon_floor(sigma: f64, bpw: f64, n: usize) -> f64 {                             // 부록 D.1 + 유한크기 CI
            sigma * 2f64.powf(-bpw) * (1.0 - 5.0 / (2.0 * n as f64).sqrt())
        }
    }
}
```

실패 메시지는 반드시 `(measured, bound, ratio)` 를 출력한다. `ratio = measured / bound > 1` 이 실패 조건이다.

## 2. L0 — 정확성 계층 (비트 동일성, 허용오차 0)

이론이 **정확**(오차 0)을 보장하는 연산은 `assert_eq!` 비트 비교로 검증한다. 근사 비교 사용 자체가 위반이다.

| 테스트 (한글 함수명) | 내용 | 근거 |
|---|---|---|
| `위상미분_정수덧셈_양자화가환_비트동일성` | 임의 위상 q 에 대해 "양자화 후 미분" == "미분 후 양자화". q 전수(2^20) 또는 b>20 이면 경계+무작위 10^6 | 정리 3.2 |
| `위상미분_4회_원상복귀` | 원형 트랙: D^4 적용 후 위상 레지스터 비트 원상복귀 (진폭은 omega^4 배 별도 확인) | 따름정리 3.2.1 |
| `쌍곡라벨_2회_플립_원상복귀` | s ^= 1 두 번 == 항등 | 정리 3.3 |
| `사분면비트_카운터_증가` | q += 2^(b-2) 가 상위 2비트를 mod-4 증가시키고 하위 비트 보존 | 따름정리 3.2.1 |
| `델타격자_n계미분_단일덧셈_동일성` | q + n*q_delta (한 번에) == q 에 q_delta 를 n 번 덧셈 (mod 2^b) | 부록 A.3-2 |
| `적분_미분_역원` | D 후 D^{-1} == 항등 (위상·라벨·로그진폭 전부 비트 동일) | 3.1절 |
| `스털벤츠_감산_정확성_전수` | r 의 f32 전수([0.5,1] 구간 약 8.4M개)에 대해 fl(1-r) 이 정확 (f64 캐스팅 비교) | 부록 E.1 |
| `연산량_카운터_공식일치` | 계측 카운터(FLOP 수, 접촉 바이트)가 15.4절 공식의 정수값과 assert_eq | 15.4절 |

속도 검증 주의: 벽시계 시간은 게이트로 쓰지 않는다(비결정적). L0 의 결정론적 카운터 일치가 게이트이고, 벽시계는 L5 벤치마크로 보고만 한다.

## 3. L1 — 이론 상계 계층 (유도된 허용오차)

각 근사 연산의 오차가 부록의 닫힌형 상계 이내인지 검증한다.

| 테스트 | 방법 | 상계 (bounds 함수) |
|---|---|---|
| `LUT_보간오차_상계준수_전수` | 위상 2^20 전수를 f64 sin 과 대조, max 오차 | `lut_interp(k)`; k=12 → 1.8375e-8 |
| `경계감산_상대오차_균일상계` | r = 1 - 2^-j (j=1..23) 격자 + 무작위 10^6, (1-r)(1+r) vs f64 | `sterbenz_product()` = 1.19e-7 |
| `소박한감산_열화_확인` | 동일 격자에서 fl(1-fl(r^2)) 의 오차가 u/(2(1-r^2)) 스케일로 커짐을 확인 (개선 폭 증명) | 부록 E.2 대조식 |
| `부제만_평가_합성상계` | z, theta_b 무작위 10^5, 구현 B vs oracle | LUT/log 항 합성 상계 함수 |
| `원자평가_양자화바닥_상계` | 다양체 위 타깃(정확한 파라미터로 합성) 인코딩→디코딩, per-weight 오차 | `atom_eval(p, r_max)`; 17.1절 (128b: 1.7e-4 스케일) |
| `해석그래디언트_중심차분_대조` | dW/dr, dW/dtheta, dW/dz(좌표) 를 f64 중심차분과 대조. h 는 `central_diff_h_opt` 로 원자별 계산, M0·M3 는 파라미터에서 산출 | `central_diff(h, m0, m3)` |
| `위상이동미분_해석식_동치` | 도함수를 (a) 위상이동 재평가 경로, (b) 해석 공식 경로로 계산해 상호 대조 | 두 경로 각각의 상계 합 |
| `tanh지름길_동치` | A - W^2/A vs A(1 - tanh^2 u) f64 | ulp 급 합성 상계 |
| `고유함수_이산라플라시안` | 미세 격자(h) 이산 라플라스-벨트라미 적용, 고유값 -(lambda^2+1/4) 대비 | O(h^2) 상계, 상수는 4계 도함수 상계에서 산출 (부록 C.1) |

## 4. L2 — 수학 항등식 계층 (성질 기반, 고정 시드 무작위)

무작위 파라미터(시드 명기, 케이스 수 >= 10^4)에 대한 항등식 검증. 내부 계산은 f64, 허용오차는 f64 반올림 전파 상계.

| 테스트 | 항등식 | 근거 |
|---|---|---|
| `부제만_대수항등식` | 2<z, z-b> + (1-\|z\|^2) == \|z-b\|^2 | 부록 B.2 |
| `부제만_단위기울기` | \|grad B\|_hyp == 1 (수치 기울기) | 부록 B.2 |
| `호로사이클_등위선` | P(z,b)=c 표본점들이 중심 (c/(c+1)), 반지름 1/(c+1) 원 위 | 부록 B.3 |
| `뫼비우스_공변성` | P(gz, gb) * \|g'(b)\| == P(z,b) | 부록 C.3 |
| `코사이클_원자변환_닫힘` | atom(g^{-1}z; p) == atom(z; g·p) — C.3 따름의 파라미터 변환 규칙 | 부록 C.3 |
| `라디얼_부제만_쌍곡거리_일치` | B_b(r·b) == 2 artanh r | 부록 F.3 |
| `분리인수분해_동치` | K(z_i, w_j) 직접 평가 == (F_out F_in^T)_ij. 내적 오차는 `dot_product(2J)` 상계 (주의: Sum\|·\| 에 상대적) | 명제 15.2, Higham |
| `게이지불변성` | 좌표·커널을 g 로 동시 변환한 층의 W 행렬 불변 | 15.7절 |
| `리만그래디언트_경계감쇠` | r -> 1 에서 갱신량이 (1-r)^2 스케일로 0 수렴, r < r_max 불변 유지 | 5.4절 |
| `사인유일성_반례부재` | (보조) 위상이동 성질을 sinh 로 시험하면 실패함을 확인하는 부정 테스트 | 명제 A.1, 정리 3.3 |

## 5. L3 — 통계·정보이론 계층 (연구 무결성 가드)

이 계층의 특수 목적은 **너무 좋은 결과를 버그·조작으로 검출**하는 것이다.

| 테스트 | 내용 | 판정 |
|---|---|---|
| `샤논하한_가드` | i.i.d. 가우시안 행렬(시드 고정)을 임의 인코더로 R bpw 압축했을 때 RMSE 가 `shannon_floor(sigma, R, n)` **미만이면 실패** — 하한 위반은 물리적으로 불가능하므로 측정 방법 또는 인코더의 버그다 | RMSE >= floor |
| `양자화기_왜곡_이론일치` | Lloyd-Max b비트 왜곡이 이론값(0.3634/0.1175/0.0345/0.0095 sigma^2) 의 `rmse_ci_rel(n)` 밴드 내 | 양측 판정 (좋아도 실패) |
| `분산축소_손익분기` | c 를 통제한 합성 데이터(구조+백색 잔차)에서 하이브리드 RMSE == 0.343 sqrt(1-c) sigma (b=2) 가 CI 내 | 17.3절 표 자체가 오라클 |
| `c_추정기_보정` | 알려진 c 로 합성한 층에서 c 추정치가 CI 내 | 프로토콜 7 예비 |

양측 판정 원칙: L3 은 "나빠도 실패, 좋아도 실패"다. 이론보다 좋은 결과는 축하할 일이 아니라 조사 대상이다.

## 6. L4 — 종단 계층 (실제 가중치, nlp-verify 규칙 준수)

skt-kogpt2 실가중치만 사용한다 (난수 가중치 검증 금지 — .claude/skills/nlp-verify).

1. `다양체위_왕복_바닥일치`: 진짜 파라미터에서 합성한 장을 그 파라미터로 초기화해 인코딩→디코딩. RMSE <= `atom_eval` 바닥. (인코더 최적화의 전역성 문제와 분리해 코덱 자체의 정합성만 게이트.)
2. `적합_수렴_비게이트_벤치`: 무작위 초기화 적합의 도달 RMSE 는 게이트가 아니라 보고 항목 (전역 최적 보장이 없으므로 — 명제 5.1 의 정직한 범위).
3. `실층_c측정_보고`: kogpt2 층별 c 를 측정해 docs/test 에 기록. 게이트 없음(측정이 목적).
4. `하이브리드_예측식_일치`: 측정된 c 를 17.3절 식에 대입한 예측 RMSE 와 실측 RMSE 가 `rmse_ci_rel` 밴드 내 (이론식이 오라클).
5. `candle_순전파_대조`: 압축 가중치 순전파 vs candle f32 기준. 오차 상계는 행렬-벡터 전파식 \|dy\| <= \|dW\|_F \|x\| 로 층별 RMSE 에서 유도 (리터럴 금지 동일 적용).

## 7. 하네스 자체의 감사(lint)

정적 감사 스크립트: `scripts/harness_lint.py` (구현 완료, 2026-08-13). `run_nlp_tests.sh` 에 앞서 실행한다:

- 테스트 파일에서 `assert!(.*< *[0-9.]+e?-?[0-9]*)` 패턴의 부동소수점 리터럴 비교 검출 시 실패 (bounds:: 경유 강제). 예외는 `0.0`, `assert_eq!` 뿐.
- 테스트 파일에서 `from_entropy` 검출 시 실패.
- `#[ignore]` 붙은 게이트 테스트 검출 시 경고 목록 출력.

## 8. 실행 계층과 CI 게이트

| 계층 | 실행 | 게이트 |
|---|---|---|
| L0, L1, L2 | `cargo test` 기본, 매 커밋 | 필수 통과 |
| L3 | `cargo test` 기본 (고정 시드라 결정론적) | 필수 통과 |
| L4 | 모델 파일 존재 시 (`#[ignore]` + 명시 실행), `run_nlp_tests.sh` | 병합 전 필수 |
| L5 벤치 | 별도 실행, 결과는 docs/test 보고서로 | 게이트 아님 (보고) |

기존 테스트 대비 변경점: 이 하네스가 도입되면 기존의 느슨한 리터럴 허용오차 테스트(예: rmsnorm 의 `< 0.2`)는 bounds 유도로 대체되어야 하며, 이는 테스트 수치 변경이므로 항목별 사용자 승인 후 진행한다.

## 9. 구현 명세 (체크포인트 공통 규약)

구현이 결정론적으로 진행되도록 핵심 타입을 여기서 확정한다. 변경 시 본 문서와 논문 4.1절을 함께 갱신한다.

### 9.1 비트 레이아웃 (논문 4.1절과 동일, 규범)

```rust
/// hi 64비트 필드 (모든 시프트 상수는 이 표에서만 정의)
/// [63:62] trk    (2)  트랙: 00 원형, 01 쌍곡, 10 tanh, 11 예약
/// [61:42] q      (20) 위상 레지스터. phi = 2*pi*q / 2^20. 상위 2비트 = 사분면
/// [41:32] m_r    (10) 반경 주파수 지수
/// [31:26] m_psi  (6)  각 파수 (정수)
/// [25]    s_h    (1)  쌍곡 라벨 (sinh=0 / cosh=1)
/// [24]    sign   (1)  부호
/// [23:8]  a      (16) 로그 진폭 코드: A = 2^((a - 32768) / 2048)
/// [7:0]   -      (8)  예약 (0)
pub struct PhaseState { pub hi: u64 }

pub const PHASE_BITS: u32 = 20;
pub const PHASE_QUARTER: u32 = 1 << (PHASE_BITS - 2);   // 2^18 = pi/2
pub const PHASE_MASK: u32 = (1 << PHASE_BITS) - 1;
```

### 9.2 원자 파라미터 (13장)

```rust
pub struct AtomParams {
    pub theta_b: f64,   // 경계점 방향 (양자화 전 해석 표현)
    pub lambda: f64,    // 스펙트럼 파라미터 (delta-격자 모드에선 lambda = 0.5 * tan(delta))
    pub phi_q: u32,     // 위상 레지스터 (20비트)

}
```

### 9.3 정밀도 정책

- 프로덕션 경로: f32. 오라클·항등식 검증: f64. 비트 동일성 검증: 정수/비트.
- 경계 연산 `1 - r^2` 은 반드시 `(1 - r) * (1 + r)` 로 구현한다 (부록 E.2). 소박한 형태는 lint 대상.
- `r_max = 1 - 2^-20` (f32). 모든 좌표·반경은 [0, r_max] 로 투영.

## 10. 구현 체크포인트 계획 (보고 단위)

각 체크포인트(CP)가 하나의 보고 단위다. **CP 완료마다 11절 양식으로 사용자에게 결과를 보고하고 다음 CP로 진행한다.** 순서는 의존성 순이다.

| CP | 구현 | 테스트 (계층) | 완료 기준 |
|---|---|---|---|
| CP-1 | `math/verification.rs` — bounds 전 함수 + oracle + check 헬퍼 | bounds 자기검증 (조견표 값 재계산 일치) | cargo test 통과, 조견표와 코드 일치 |
| CP-2 | `math/phase_state.rs` — 비트 필드 접근자, 위상 양자화, 미분/적분 상태 전이 | L0 전체 7종 (비트 동일성; 위상 2^20 전수, Sterbenz f32 전수) | L0 전 항목 오차 0 |
| CP-3 | `math/lut.rs` — 사분파 sin LUT (k=12) + 보간 | L1: 보간오차 전수 스윕 vs oracle | max 오차 <= `lut_interp(12)` |
| CP-4 | `math/busemann.rs` — P, B_b, 뫼비우스 작용 | L1 합성상계 + L2 항등식 5종 (대수·단위기울기·호로사이클·공변성·라디얼 일치) | 전 항등식 f64 상계 내 |
| CP-5 | `math/atom.rs` — 원자 평가·위상이동 미분·tanh 지름길 | L1: 중심차분 대조(h 자동 산출), 두 미분 경로 동치, 양자화 바닥 | 전 항목 ratio <= 1 |
| CP-6 | `matrix/layer_codec.rs` — 좌표+원자 층, 분리 인수분해 순전파 | L2: 분리 동치(Higham 상계)·게이지 불변성; L0: FLOP/바이트 카운터 공식 일치 | 카운터 정수 일치 + 상계 내 |
| CP-7 | `encoder/hybrid_codec.rs` — 잔차 양자화, c 추정기 | L3 전체 (샤논 가드·Lloyd-Max 양측·손익분기·c 보정) | 양측 판정 통과 |
| CP-8 | kogpt2 연결 (기존 model_tools 확장) | L4 (다양체 왕복 게이트, c 실측 보고, candle 대조) | 게이트 통과 + c 보고서 |

범위 규율: 각 CP 에서 기존 코드 수정은 모듈 선언 추가로 한정한다. 기존 테스트를 깨뜨리는 변경 금지 (규칙 4).

## 11. 체크포인트 보고 양식

각 CP 완료 시 다음을 보고한다:

1. **구현 요약**: 추가/수정 파일, 공개 API, 논문 근거 절.
2. **테스트 결과 표**: 테스트명(한글) | 케이스 수 | measured | bound | ratio. L0 은 "비트 동일 / 케이스 수". 실패 0 이어야 완료.
3. **이론 대비 관찰**: ratio 가 1 에 가까운 항목(여유 부족), 이론 상계보다 크게 좋은 항목(상계가 느슨한지 검토).
4. **미해결/보류**: 발견했으나 이번 CP 범위 밖인 문제.
5. **다음 CP 착수 여부**.

## 12. 실패 대응 프로토콜 (triage)

테스트 실패(ratio > 1) 시 허용되는 대응은 다음뿐이다:

1. **구현 수정** (기본): 오차 원인을 찾아 구현을 상계 안으로 넣는다.
2. **유도 오류 발견 시**: 논문 부록을 먼저 수정하고(사용자 보고), bounds 함수를 새 유도로 갱신한 뒤 재실행.
3. **금지**: bounds 값 완화, 테스트 삭제, `#[ignore]` 추가, 케이스 수 축소로 통과시키기. 이 중 어느 것도 필요해 보이면 작업을 멈추고 사용자에게 보고한다.

L3 양측 판정에서 "이론보다 좋음" 실패가 나면: 측정 코드 버그(가장 흔함) → 오라클 대조 → 그래도 좋으면 이론 상계의 가정 위반 여부(소스가 가우시안이 아님 등)를 조사해 보고한다.
