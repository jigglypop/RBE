# Legacy → Enhanced128 포팅 구현 타임라인

## 예상 소요 시간: **총 3-5일** (풀타임 기준)

## 1. 구현 난이도 분석

### 쉬운 부분 ✅
- Legacy 코드가 이미 잘 구조화되어 있음
- 수학 함수들이 명확히 분리되어 있음
- 현재 시스템의 비트 연산 인프라 재사용 가능
- 테스트 프레임워크가 이미 구축됨

### 어려운 부분 ⚠️
- 12가지 기저 함수를 LUT로 정확히 변환
- 고정소수점 연산의 정밀도 튜닝
- 기존 NLP 레이어들과의 호환성 유지
- 성능 최적화 (목표: 1.5x 이하 속도 저하)

## 2. 단계별 작업 및 예상 시간

### Phase 1: LUT 생성 인프라 (0.5-1일)
```
├── build.rs 수정 (2시간)
│   └── LUT 생성 함수 추가
├── generate_basis_luts.rs 작성 (4시간)
│   ├── Bessel 함수 구현/검증
│   ├── Morlet wavelet 구현
│   └── 고정소수점 변환 로직
└── basis_lut.rs 자동 생성 확인 (2시간)
```

### Phase 2: Enhanced128 코어 구현 (1-1.5일)
```
├── enhanced_types.rs 생성 (3시간)
│   ├── Enhanced128 구조체
│   ├── 비트 필드 디코딩
│   └── 파라미터 추출 메서드
├── fused_forward_enhanced 구현 (4시간)
│   ├── 좌표 변환 로직
│   ├── LUT 조회 최적화
│   └── 고정소수점 연산
└── 단위 테스트 작성 (3시간)
```

### Phase 3: 압축/복원 시스템 통합 (0.5-1일)
```
├── WeightCompressor 수정 (3시간)
│   └── Enhanced128 시드 생성 로직
├── WeightDecompressor 수정 (2시간)
│   └── Enhanced128 복원 로직
└── TransformStats 확장 (1시간)
```

### Phase 4: NLP 레이어 마이그레이션 (1일)
```
├── RBELinear 수정 (2시간)
│   └── Packed128 → Enhanced128 전환
├── 다른 레이어들 수정 (4시간)
│   ├── Embedding
│   ├── Attention
│   └── LayerNorm
└── 호환성 테스트 (2시간)
```

### Phase 5: 성능 검증 및 최적화 (0.5-1일)
```
├── 벤치마크 작성 (2시간)
│   └── Legacy vs Current vs Enhanced
├── 성능 프로파일링 (2시간)
└── 병목 지점 최적화 (2-4시간)
```

## 3. 리스크 및 대응 방안

| 리스크 | 확률 | 영향 | 대응 방안 |
|--------|------|------|-----------|
| LUT 정밀도 부족 | 중 | 높음 | Q20.12 or Q24.8 포맷으로 전환 |
| 성능 목표 미달 | 낮음 | 중간 | SIMD 최적화, 캐시 라인 정렬 |
| 기존 모델 호환성 | 중 | 높음 | Packed128 폴백 옵션 제공 |
| Bessel 함수 정확도 | 높음 | 중간 | 고차 근사 or 외부 라이브러리 |
