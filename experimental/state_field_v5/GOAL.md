# 사용자 목표 — 다음 개발에서도 유지할 계약

목표는 RBE의 상태 전이 원리를 이용해, 가중치까지 비트필드로 보관하고
같은 컴퓨트 셰이더에서 순전파·입력 역전파·가중치 역전파를 처리하는 것이다.
리만기하학은 이름이 아니라 변환 또는 학습 계량에 실제로 작용해야 한다.
양자화는 허용하되, 정한 양자화 모델보다 추가로 정확도를 잃는 변환은
별도 오차로 측정하고 표시한다. 상태 항수를 숨겨서 늘리거나 프루닝으로
없애지 않는다. 속도와 압축률은 실제 기기·전체 모델 단위로 검증한다.

## 이번 v5에서 고정한 것

- 같은 비트평면 코드에서 Y, dX, dW를 정확한 정수 내적으로 계산한다.
- 2~16비트 정밀도를 지원하며, 합산은 두 uint32의 int64로 보존한다.
- 로컬 블록은 한 dispatch에서 리만 가중치 갱신까지 실행한다.
- 실제로 나중에 계산되는 upstream을 미리 쓸 수 있다고 주장하지 않는다.
- 큰 레이어는 같은 셰이더의 타일 계산과 정확한 합산 두 단계가 필요하다.
- 리만 가중치에는 푸앵카레 계량과 경계 검사, 정수 잔여값 보정을 사용한다.
- 일반 양자화 행렬의 모든 계수는 보존한다. 작은 기하곱 계수 수로 모든
  Dense 행렬을 표현·압축할 수 있다는 주장은 하지 않는다.

## 다음 우선순위

1. v3의 정확한 부호·순열 합성과 구조적 블록을 v5 계수 커널에 연결하여
   수행할 곱셈 자체를 제거한다. 일반 행렬은 정확한 quantized 경로를 유지한다.
2. 물리 GPU에서 packed integer dot/subgroup/공유메모리 배치를 측정한다.
   AND/popcount 경로가 무조건 빠르다는 전제는 두지 않는다.
3. 실제 모델의 레이어별 허용오차로 정밀도를 배정하고, 고정된 미사용
   평가셋의 과제 정확도 및 전모델 바이트·메모리·처리량을 기록한다.
4. 전역 gradient 합산 이후의 다중 타일 optimizer를 완성한다.
   서로 다른 workgroup이 공유 가중치를 동시에 갱신하게 두지 않는다.

현재 확인하지 않은 목표: 전체 LLM 변환의 정확도, 전체 LLM 학습,
물리 GPU 가속 배수, 모든 비선형·정규화 연산을 포함한 완전한 단일 실행.
