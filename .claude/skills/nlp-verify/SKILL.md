# NLP 레이어 검증 플로우

인자: 대상 레이어 (예: `linear`, `attention`, `ffn`, `layernorm`).

## 검증 기준 (절대 규칙)

- 실제 모델 가중치(skt-kogpt2)만 검증 기준으로 허용한다. 난수 가중치·더미 가중치로 "통과"를 만드는 것은 기만 행위다.
- candle(`candle-core`/`candle-nn`)로 동일 레이어의 순전파·역전파를 수행하고, RBE 구현 결과와 비교한다.
- 세 가지 축을 모두 측정한다: 정확도(candle 대비 오차), 압축률, 속도.

## 절차

### 1. 기존 검증 코드 확인

`src/nlp/<레이어>/__tests__/` 와 `src/nlp/candle_comparison_test.rs`, `src/nlp/accuracy_utils.rs` 를 먼저 읽는다. 기존 비교 테스트가 있으면 새로 만들지 말고 그것을 실행·확장한다.

### 2. 모델 가중치 준비 확인

skt-kogpt2 가중치가 로컬에 있는지 확인한다 (`src/nlp/model_tools/downloader.rs` 경로 규칙 참조). 없으면 다운로드가 필요하다고 사용자에게 알린다 (대용량 다운로드는 임의 실행하지 않는다).

### 3. 비교 테스트 실행

```bash
cargo test nlp::<레이어>::__tests__ -- --nocapture
```

candle 비교 테스트가 포함된 경우 그 출력에서 오차·속도 수치를 수집한다.

### 4. 판정

- 정확도: candle 결과 대비 오차가 테스트에 정의된 허용치 이내인가. 허용치 자체를 바꾸지 않는다
- 순전파·역전파 모두 비트 상태 미분 원칙을 지키는가 (인코딩은 최초 1회만)
- 결과를 통과/실패 그대로 보고한다. 실패를 통과로 보이게 하는 어떤 조작도 금지

### 5. 보고

측정된 수치를 표로 정리해 보고한다. 측정하지 못한 항목은 "미측정"으로 명시한다.
